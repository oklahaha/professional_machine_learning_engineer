    3.2 merge vs concat

    a = pd.DataFrame({'id': [1, 2, 3], 'name': ['Amy', 'Bob', 'Carl']})
b = pd.DataFrame({'id': [2, 3, 4], 'score': [80, 90, 70]})

pd.merge(a, b)                      # default how='inner'，自動用共同 column 'id' → id 2, 3（2 rows）
pd.merge(a, b, how='outer')         # id 1–4（4 rows），冇嘅位填 NaN
pd.merge(a, b, how='left')          # 保留 a 全部：id 1, 2, 3
pd.merge(a, b, on='id', how='right')   # 保留 b 全部：id 2, 3, 4

c = pd.DataFrame({'id': [5], 'name': ['Dan']})
pd.concat([a, c])                   # axis=0：上下疊 → 4 rows；index 會係 0,1,2,0（可加 ignore_index=True）
pd.concat([a, b], axis=1)           # 左右並排，按 index 對齊，唔理 'id' 內容
    ⭐ 點認 merge / concat 結果
    • Merge：兩表有共同 column，其他 columns 按共同 column 重新對齊；inner 只留兩邊都有嘅 key，outer 留晒（有 NaN），left / right 留一邊。
    • Concat：columns（或 index）相同，唔會重新排，只係直接疊埋。axis=0（default）上下疊，axis=1 左右並排；join='outer'（default）唔一致嘅 columns 填 NaN，join='inner' 只留共同 columns。
    • 見到 index 重複（0,1,2,0）→ 多數係 concat；見到同一個 key 嘅資料拼埋喺同一行 → merge。

df.loc[df['age'] > 30]                              # 條件
df[(df['dept'] == 'IT') & (df['age'] < 50)]         # 多條件：& / |，每個條件加括號

df.loc[df['age'] > 30, ['name', 'salary']]          # 2-D：揀 rows + columns

    ⭐ loc vs iloc 結尾

    df.loc[m:n] 用 label，m 同 n 都包括；df.iloc[m:n] 用 integer position，包 m 唔包 n（同 Python slicing 一樣）。條件組合唔可以用 and / or，要用 & / | 同括號。

df.isna().sum(axis=1)           # 每行有幾多 NaN

    ⭐ Missing values 重點
    • 唔好寫 df['age'] == np.nan：NaN 唔等於任何嘢（包括自己），結果永遠 False；要用 isna()。
    • dropna(thresh=x)：x = 每行最少要有幾多個非 missing 值先保留（唔係「最多幾多個 NaN」）。
    • Impute 策略：constant；statistics（mean：冇大 outliers；median：有大 outliers）；models（features 之間有 correlation 先有用）。Sklearn imputer 嘅 coding 唔使識。

    4.3 Outliers

    df.describe()                        # numeric columns：count, mean, std, min, 25%, 50%, 75%, max
df.describe(include='object')        # 非數值 columns：count, unique, top（最常見）, freq
                                     #（pandas 3 將 strings 改為 str dtype，用 exclude='number' 最穩陣）
df['dept'].mode()[0]                 # 最常見嘅值（mode() 回傳 Series）
df['dept'].value_counts().idxmax()   # 同上

Q1 = df['age'].quantile(0.25)
Q3 = df['age'].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
n_out = ((df['age'] < lower) | (df['age'] > upper)).sum()   # outliers 數目
df['age_capped'] = df['age'].clip(lower, upper)              # cap：細過 lower 變 lower，大過 upper 變 upper
    $$ \text{IQR} = Q_3 - Q_1,\quad \text{lower} = Q_1 - 1.5 \times \text{IQR},\quad \text{upper} = Q_3 + 1.5 \times \text{IQR} $$

    Five-number summary = min、\(Q_1\)（25%）、median（50%）、\(Q_3\)（75%）、max。

    💡 用 §0 個 df 計一次（drop_duplicates 之後）

    age = 25, 32, NaN, 45, 120（NaN 唔計）。pandas 用 linear interpolation：\(Q_1 = 30.25\)、\(Q_3 = 63.75\)、IQR = 33.5；upper = 63.75 + 50.25 = 114。所以 120 係 outlier（1 個），cap 之後變 114。

    5.2 Scaling（coding 唔使識）

    Why scaling：features 嘅單位 / 範圍唔同（例如 salary 幾萬、age 幾十），distance-based methods（例如 K-means、KNN）會被大數值 feature 主導。

    Standard scalingMin-max scalingRobust scaling
    公式\( \frac{x - \text{mean}}{\text{std}} \)\( \frac{x - \min}{\max - \min} \)\( \frac{x - Q_2}{Q_3 - Q_1} \)
    結果mean 0、std 1training data 喺 [0, 1]median 0、IQR 1
    Pros常用；保留 distribution 形狀固定 range，易理解Robust to outliers
    Consmean / std 受 outliers 影響；唔會令 data 變 Normal對 outliers 最敏感（一個極端值會將其他值擠埋一齊）Range 唔固定，唔保證喺 [0, 1]

    5.3 Encoding（syntax 唔使識，要識揀）

    Variable例子Encoding
    Nominal（names，唔可以排序）dept、color、cityOne-hot（或 binary）encoding：每個類別一個 0/1 column
    Ordinal（可以排序）junior < mid < senior；Good < Moderate < UnhealthyOrdinal encoding：按次序變 0, 1, 2…
    pd.get_dummies(df['dept'])     # one-hot 示意（考試唔要求寫 encoder syntax）
    ⚠️ 點解 nominal 唔用 ordinal encoding

    將 IT=0、HR=1、Sales=2 會令 model 以為 Sales > HR > IT、而且 Sales 同 IT 嘅「距離」係 HR 同 IT 嘅兩倍，製造咗唔存在嘅次序。

    5.4 Binning：cut vs qcut

    df['age_group'] = pd.cut(df['age'], bins=[0, 30, 60, 150],
                         labels=['young', 'middle', 'senior'])   # 自己俾 edges；(0, 30], (30, 60], (60, 150]
df['salary_band'] = pd.qcut(df['salary'], q=2, labels=['low', 'high'])   # 按 quantile 分，每組數量差唔多
    ⭐ cut vs qcut

    pd.cut：俾 edges（或者 bins 數 → 等寬），每個 bin 嘅 range 固定，數量可以好唔平均；default 係 right-inclusive（包右唔包左）。pd.qcut：俾 quantiles 數 q，每個 bin 數量差唔多，但 range 唔等寬。labels 數目 = bins 數目（= edges 數 − 1）。

    ⚠️ Revision slide 寫法

    Slide 8 寫 df.cut() / df.qcut()，但 pandas 入面佢哋係 top-level functions：pd.cut(series, ...)、pd.qcut(series, ...)；DataFrame 冇 .cut() method。考試寫 pd.cut。

    ⭐ axis 記法

    ⚠️ Revision slide 例子要改兩處

    Slide 9 嘅例子 df.apply(lambda x: "OK" if x[col1] > 10 & x[col2] == 5 else "not OK")：

    1. 漏咗 axis=1：冇 axis=1，x 係一個 column（Series），x[col1] 會用 column name 去搵 row label → KeyError。
    2. & 嘅優先次序高過 > / ==：x[col1] > 10 & x[col2] == 5 會被解讀成 x[col1] > (10 & x[col2]) == 5。逐行 apply 時 x[col1] 係單一值，用 and；或者每個條件加括號 (x[col1] > 10) & (x[col2] == 5)。

    正確：df.apply(lambda x: "OK" if (x[col1] > 10) and (x[col2] == 5) else "not OK", axis=1)

    # mode() 輸出

    Callerdf.groupby(...)，之後要接 aggregation（.mean()、.agg()…）df.pivot_table(...) 或 pd.pivot_table(df, ...)
    主要 optionsby（column 或 list）、之後揀 column 同 functionvalues、index、columns、aggfunc（default 'mean'）、margins、fill_value

    ⭐ 常見題型
    • 由結果反推 statement：睇 index 係乜（groupby key / pivot index）、columns 係乜（pivot columns）、數值係 mean / sum / count。見到 categories 同時喺行同列、或者有 All → pivot table。
    • 讀 trend：寫完整句子，例如用 §0 個 df（drop_duplicates 後）：「HR 嘅平均 salary 最高（42,000），IT 次之（約 39,333）」，指出最高 / 最低、隨時間上升 / 下降。
    • 點解 sampling 唔用頭 200 個：data 通常有次序（按時間、station、類別排），頭 200 行唔代表整體 → bias。用 df.sample(n=200, random_state=42) 隨機抽。
    df.select_dtypes('number').corr()      # 先揀 numerical columns（或 df.corr(numeric_only=True)）
df['age'].corr(df['salary'])
    ⭐ Correlation 解讀
    • 範圍 −1 至 1。正數：一個變大另一個傾向變大（positively correlated / 正比傾向）；負數：一個變大另一個傾向變細（negatively correlated）；接近 0：冇 linear 關係。
    • |r| 越接近 1 越 highly correlated。Correlation ≠ causation。
    • Highly correlated 可以點用：用 model impute missing values（用相關 feature 預測）；dimension reduction（刪一個 / 合併，減少 redundancy）；用嚟做 prediction。

    9. BIG DATA AND ETHICS（slide 12）

    詳見 Week 12。

    ⭐ 要識
    • Hardware 速度：CPU > Memory (RAM) > SSD > Network（200× / 15× / 20×）。CPU = brain、RAM = short-term quick storage、SSD = long-term safe storage、Network = connection、GPU = massively parallel processor。
    • 一部 vs 一組 PC：data 放得落 RAM → 一部；file 遠大過 memory（swapping、I/O wait）或 process 好複雜（DNN）→ distributed。
    • Distributed vs parallel：每個 CPU 有自己 memory、經 network 連接 vs 多個 CPU 共用 memory。
    • 4 challenges：Partitioning（data skew）、Communication overhead、Fault tolerance、Consistency & reproducibility。
    • 4 components：common utilities、data storage、job scheduler、data processing。
    • Spark vs Hadoop：Hadoop 將 intermediate results 寫 disk；Spark keep in memory → 更快。
    • 5 Cs：Consent、Clarity、Consistency、Control (and transparency)、Consequences (and harms)。
    • Distributed computing ethics：privacy、security、accountability、bias & fairness。GenAI ethics：bias、data permission、black box、unequal access；privacy、liability、environment、over-reliance、IP、malicious use。

    自我測驗 Self-test

    Q1. s = 'Computing'，s[1:7:2] 同 s[-3:] 係乜？

    s[1:7:2] 攞 index 1、3、5 → 'opt'（o、p、t）。s[-3:] → 'ing'。Start 包括、stop 唔包括。

    Q2. df.loc[2:4] 同 df.iloc[2:4] 分別有幾多行（index 係 0–9 嘅 RangeIndex）？

    loc[2:4]：labels 2、3、4 → 3 行。iloc[2:4]：positions 2、3 → 2 行。

    Q3. 寫 statement：揀出 IT dept 而 salary 大過 35000 嘅員工嘅 name 同 salary。

    df.loc[(df['dept'] == 'IT') & (df['salary'] > 35000), ['name', 'salary']]

    Q4. 表 A 有 id 1, 2, 3；表 B 有 id 2, 3, 4。pd.merge(A, B)、pd.merge(A, B, how='outer')、pd.concat([A, B]) 各有幾多行？

    Merge default inner → 2 行（id 2、3）。Outer → 4 行（id 1–4，冇 match 嘅位 NaN）。Concat（axis=0）→ 6 行，直接上下疊，index 0,1,2,0,1,2。

    Q5. 一個 DataFrame 有 6 個 columns。df.dropna(thresh=4) 會刪走邊啲 rows？

    刪走非 missing 值少過 4 個嘅 rows，即係有 3 個或以上 NaN 嘅 rows。

    Q6. 寫 code 計 price 嘅 IQR outlier 數目，然後 cap 佢哋。

    Q1 = df['price'].quantile(0.25); Q3 = df['price'].quantile(0.75)
IQR = Q3 - Q1
lower, upper = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR
n = ((df['price'] < lower) | (df['price'] > upper)).sum()
df['price'] = df['price'].clip(lower, upper)

    Q7. 「T-shirt size（S, M, L, XL）」同「country」分別用咩 encoding？點解？

    Size 係 ordinal（有次序）→ ordinal encoding（S=0、M=1、L=2、XL=3）。Country 係 nominal（冇次序）→ one-hot（或 binary）encoding，避免製造假次序。

    Q8. 有大量 outliers 嘅 feature 應該用邊種 scaling？Min-max 有乜問題？

    Robust scaling（用 median 同 IQR，唔受 outliers 拉動）。Min-max 用 min / max，一個極端值會將其他正常值擠埋喺好窄嘅範圍，對 outliers 最敏感。

    Q9. 用 apply 整新 column status：如果 age > 40 而且 salary < 45000 就係 'review'，否則 'ok'。

    df['status'] = df.apply(lambda x: 'review' if (x['age'] > 40) and (x['salary'] < 45000) else 'ok', axis=1)。記得 axis=1。

    Q10. 用 agg：age 顯示 mean 同 max，salary 顯示 sum 同自定義 function value_range。

    df.agg({'age': ['mean', 'max'], 'salary': ['sum', value_range]})。Built-in 用引號；user-defined function 直接寫名。

    Q11. 一個結果嘅 rows 係 dept（HR、IT、Sales、All），columns 係 level（junior、mid、senior、All），值係平均 salary。係 groupby 定 pivot table？寫出 statement。

    Pivot table（二維、有 All 總計）：df.pivot_table(values='salary', index='dept', columns='level', aggfunc='mean', margins=True)

    Q12. 點解唔用頭 200 行做 sample？

    Data 多數有排序（時間、地點、類別），頭 200 行可能只代表某段時間或某一組，有 bias；應該用 df.sample(n=200, random_state=...) 隨機抽樣。

    Q13. 一部 8 GB RAM 嘅電腦處理 200 GB log file 冇反應，原因？應該點做？

    Data 遠大過 RAM，OS 要不停 swapping / paging，memory 來唔切由 storage load data，CPU 大部分時間喺 I/O wait。應該用 distributed computing（例如 Spark），將 data partition 去多部機處理。

    Q14. 解釋 5 Cs 入面嘅 Consent 同 Control。

    Consent：就收集咩 data、點用達成協議，建立 trust。Control (and transparency)：user 可以控制 service 點用佢嘅 data。

    一頁總結 Cheat sheet

    ⭐ 考前速記
    • Nominal（冇次序）→ one-hot；Ordinal（有次序）→ ordinal encoding。5 Vs：Volume、Velocity、Variety、Veracity、Value。
    • Python：indentation、case sensitive、interpreted。[a:b:c] 包 a 唔包 b。list [] mutable；tuple () immutable；set 冇次序冇重複；dict key–value。Accumulator 喺 loop 前 initialize。
    • def f(x, y=1): return ...；lambda x: expr。
    • CSV = text、冇 dtypes；pickle = binary、保留 dtypes。merge default inner、按共同 column 對齊；concat 直接疊，axis=0 上下、axis=1 左右。
    • Attributes 冇括號（shape、columns、index）；methods 有括號。loc 包尾、iloc 唔包尾；條件用 & / | + 括號。
    • duplicated() / drop_duplicates() / drop(columns=)；nunique()==1 → constant。
    • isna().sum()；唔好 == np.nan；dropna(thresh=x) 最少 x 個非 NaN；fillna(median) 有 outliers 時用。
    • IQR：\(Q_1 - 1.5\,\text{IQR}\)、\(Q_3 + 1.5\,\text{IQR}\)；clip(lower, upper) cap。describe(include='object') → top / freq。
    • .str.strip() / .lower() / .contains() / .str[:3]；pd.to_datetime + .dt.year / .month / .quarter。
    • Scaling：Standard（mean/std）、Min-max（最怕 outliers，[0,1]）、Robust（median/IQR，抗 outliers）。pd.cut（edges）vs pd.qcut（quantiles）。
    • map：Series、one-to-one、冇 axis、唔可以 aggregate；apply：axis=0 逐 column、axis=1 逐行；agg：唔同 column 唔同 function，built-in 加引號。
    • numeric_only=True、describe(include=)、select_dtypes()。mode() 回傳 Series / DataFrame。
    • groupby（長形、要接 aggregation）vs pivot_table（二維、margins）。Random sample 避免 bias。corr() 只計 numerical；r 正 / 負 / 近 0。
    • Heatmap → corr；hist → distribution；count plot → categorical 數量；hue / col / size 加 features。
    • Big data：CPU > RAM > SSD > Network；data > RAM → distributed；distributed（own memory）vs parallel（shared）；4 challenges；Hadoop disk vs Spark memory；5 Cs。
