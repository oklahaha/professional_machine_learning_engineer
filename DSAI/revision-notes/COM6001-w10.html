    ⭐ 考試必溫 Top-5

    1. Groupby = split → apply → combine；df.groupby(by=…) 本身只係一個 DataFrameGroupBy object（(key, sub-DataFrame) tuples），要再套 function 先有結果。
    2. count() = 每個 column 嘅 non-NA 數目（DataFrame）；size() = 每個 group 嘅總行數（Series，包 NaN）。

    5. pd.pivot_table(df, values=, index=, columns=, aggfunc='mean', fill_value=, margins=)：groupby 只會將 groups 放喺 index，pivot table 可以將 groups 同時放喺 index 同 columns（2D grouping）；考試會要你由 output 寫返個 statement。

    1. Group By 概念

    ⭐ Groupby 三步曲
    1. Split：根據某啲 criteria（categorical groupers）將 data 分成 groups。
    2. Apply：對每個 group 獨立套用一個 function。
    3. Combine：將各 group 嘅 function 結果合併成一個 data structure。

    用途例子：計每個 category group 嘅 statistics（例如每個月嘅平均 PM2.5）。

    🖼️ groupby.png（PDF 第 3 頁）

    左邊 my_data：type / value = (a, 5)、(a, 3)、(b, 7)、(a, 8)、(b, 2)。Split based on type 分成兩個細 table：a 組 (5, 3, 8) 同 b 組 (7, 2)。每組各自 apply mean()：a → 5.33、b → 4.5。最後 Combine 成一個結果 table：type a 5.33、b 4.5。即係 my_data.groupby('type')['value'].mean()。

    1.1 Syntax

    DataFrame.groupby(by=None, axis=0, level=None,
                  as_index=True, sort=True,
                  group_keys=True, squeeze=NoDefault.no_default,
                  observed=False, dropna=True)
    • by：mapping、function、label，或者 list of labels。如果 by 係 function，會對 object 嘅每個 index value call 一次；如果傳 dict 或 Series，就用 dict / Series 嘅 VALUES 決定 groups。最常用係傳 column name（label）或 list of column names。
    • axis：{0 or 'index', 1 or 'columns'}，default 0。
    • 其他參數（講義冇詳細講）：as_index=True 令 grouper 變 index；sort=True 將 group keys 排序；dropna=True 會掉走 grouper 係 NaN 嘅 rows。
    • Returns：DataFrameGroupBy，一個包含 groups 資訊嘅 groupby object。

    ⭐ count() vs size()
    count()size()
    計乜Non-null valuesAll values（the shape），包括 NaN

    如果某 group 嘅 count() < size()，代表嗰個 column 喺嗰個 group 有 missing values：逐組逐欄數學上係 size 減 count，但 Series / DataFrame 直接相減會按 columns 錯誤對齊。正確：g = df.groupby('g'); missing = g.count().rsub(g.size(), axis=0)，explicit 按 group index broadcast。

    🔗 連繫

    同 Week 9 嘅 df.count()（成個 DataFrame 每 column 嘅 non-NA 數）同 df.shape 一樣道理，只係而家係「每個 group 各自計」。用 g.count().rsub(g.size(), axis=0) 搵 missing values 嘅分佈，連返 Week 6 missing values 分析（例如睇 missing 係咪集中喺某個 station → 可能唔係 MCAR）。

    3. 對 groups 套用 built-in functions

    可以對分好嘅 groups 套其他 built-in functions。Default 係對每個 group 獨立套用，好似對幾個 mini DataFrames 分別套用咁。例如 mean() 會對每個 grouped DataFrame 計，結果再 combine 成一個 DataFrame。

    ⭐ .groupby().mean() 規則
    • Output 唔會包括 grouper column（grouper 變咗 index）。
    • 跟住嘅 function 會套用喺所有 non-grouper columns。
    # automatically excludes the grouper column ('type')
my_data.groupby(by='type').mean()
#       value      size
# type
# a       6.5  2.333333
# b       4.5  4.000000

    手計 check（呢個係有 NaN 嗰個版本）：group a 嘅 value = (5 + 8) / 2 = 6.5（NaN 自動略過）；size = (1 + 2 + 4) / 3 ≈ 2.333。Group b：value = (7 + 2) / 2 = 4.5；size = (3 + 5) / 2 = 4。

    air_quality.groupby(by='month').mean(numeric_only=True)
#            PM2.5        PM10        SO2  ...       TEMP ...
# month
# 1      98.547996  118.321682  30.437413  ...  -1.705837
# ...
# 8      56.235265   77.137440   4.601087  ...  26.834656
# ...
# 12    115.889403  143.330803  24.262568  ...  -0.070568

    Air quality 有 object columns（wd、station、day_of_week_name）同 category columns，計唔到 mean，所以要加 numeric_only=True（同 Week 9 嘅 df.mean(numeric_only=True) 一樣）。

    4. Time profiling：group / function / selection 嘅次序

    通常我哋只關心某啲 features 嘅 statistics，所以會加一個 selection 步驟。例如想知每個 quarter 嘅平均溫度：按 quarter groupby，再對每個 group 套 mean。所以典型 groupby 操作有三步：group、function、selection。三步可以用唔同次序達到同一結果，但速度唔同。

    %%timeit
air_quality.groupby(by='quarter').mean(numeric_only=True)['TEMP']
# Group -> function -> selection
# full scale grouping and mean()；slow speed but short code
# 6.09 ms ± 54.7 μs per loop

%%timeit
air_quality[['TEMP','quarter']].groupby(by='quarter').mean(numeric_only=True)
# Selection -> group -> function
# long code but modest speed
# 1.59 ms ± 23 μs per loop

%%timeit
air_quality.groupby(by='quarter')['TEMP'].mean(numeric_only=True)
# Group -> selection -> function
# fast speed and short code
# 956 μs ± 12.9 μs per loop
    ⭐ 三種次序比較
    次序寫法時間評語
    Group → Function → Selectiondf.groupby('quarter').mean(numeric_only=True)['TEMP']6.09 ms最慢：所有 numeric columns 都計咗 mean，最後先揀 TEMP（浪費）；code 短
    Selection → Group → Functiondf[['TEMP','quarter']].groupby('quarter').mean()1.59 ms中等：先 copy 一個細 DataFrame；code 長
    Group → Selection → Functiondf.groupby('quarter')['TEMP'].mean()956 μs最快又短：split 完只對 TEMP 計

    原則：越早減少要計嘅 columns 越好，而且唔好計完先掉。最快約為最慢嘅 6 倍（6.09 / 0.956 ≈ 6.4）。

    💡 Output 形狀

    groupby('quarter')['TEMP'].mean() 回傳 Series；groupby('quarter')[['TEMP']].mean() 回傳 DataFrame。第二種寫法 (Selection → Group → Function) 回傳 DataFrame。考試由 output 反推 code 時要留意有冇 column header。

    🔗 連繫：COM6002 SQL

    groupby 就係 SQL 嘅 GROUP BY：df.groupby('quarter')['TEMP'].mean() ≈ SELECT quarter, AVG(TEMP) FROM air_quality GROUP BY quarter;。SQL 都係只 SELECT 需要嘅 columns 先有效率。見 COM6002 Week 4 SQL。

    5. 套用 custom-defined functions：agg()

    用 df.groupby().agg() 將自己 define 嘅 function 套落每個 group。Function 收到嘅係每個 group 嘅一個 column（Series），要回傳一個值。

    def max_min(col):
    return col.max() - col.min()      # range / span

# PM2.5    819.0
# dtype: float64

# quarter
# 1        818.0  992.0
# 2        531.0  984.0

    自訂 function 傳入時唔加引號、唔加括號（agg(max_min)，唔係 agg('max_min') 或 agg(max_min())）。

    6. 用 agg() 一次套多個 functions

    ⭐ list vs dict
    • df.groupby().agg([function list])：對所有 non-grouper columns 套同一組 functions。
    • df.groupby().agg({function mapping})：對唔同 non-grouper columns 套唔同 functions。
    • 例：air_quality.groupby('quarter').agg({'TEMP': ['mean', 'max'], 'PM2.5': 'mean'})

    8. Pivot table 概念

    Groupby 永遠只將 groups 顯示喺 index。如果想將某啲 groups 顯示喺 columns 呢？就用 PivotTable。

    • PivotTable 係一個強大嘅工具，可以 slice and dice data。
    • 可以用一個精簡嘅 table 追蹤同分析幾十萬個 data points，從唔同角度睇 data。
    • 支援喺 indices 同 columns 兩邊按 keys 做 aggregation（2D grouping）。
    🖼️ pivot.png（PDF 第 17 頁）

    Excel PivotTable 截圖：表頭 "Sum of SALES"，rows 係 MONTH（January、February、April…December），每個月下面再分 CUSTOMER（Foo Bars、123 Warehousing、Acme, inc.、Demo Company、Smith and Co.、ABC Telecom、Fake Brothers、Widget Corp），columns 係 YEAR（2014、2015），格入面係 SALES 總和（例如 February / 123 Warehousing：2014 年 2,000,000、2015 年 0）。右邊 PivotTable Fields 面板：兩條箭咀顯示 ROWS 放咗 MONTH 同 CUSTOMER，COLUMNS 放 YEAR，VALUES 放 Sum of SALES。對應 pandas：pd.pivot_table(df, index=['MONTH','CUSTOMER'], columns='YEAR', values='SALES', aggfunc='sum')。

    ⭐ Key parameters
    Parameter意思
    values要套 aggfunc 嘅 column(s)（被計算嘅數）

    ⚠️ 'mode' 唔可以直接放入 agg

    ⚠️ pd.Series.mode vs lambda x: x.mode()[0]

    如果某個 group 有兩個並列 modes，pd.Series.mode 會喺嗰格放一個 array（例如 ['N','S']），而 x.mode()[0] 只會攞 sorted 後第一個。要處理 all-null group，否則 mode 為空會 IndexError；可用 lambda s: s.mode().iloc[0] if not s.mode().empty else np.nan 保證 scalar。Callable 多值輸出亦可能因 version / data 改變，唔好假設所有情況都接受 array。

    heatmap：PM2.5、TEMP、WSPM、RAIN、quarter 五個 variables 嘅 correlation matrix，格入面有數字（即係用咗 annot=True），顏色由藍（負）經白到紅（正）。對角線全部係 1；最強嘅係 PM2.5 vs WSPM = −0.28（風速越大，PM2.5 越低）；其次 WSPM vs quarter −0.16、TEMP vs quarter 0.15、PM2.5 vs TEMP −0.14；其他差唔多係 0。由藍白紅嘅配色推斷，cmap 應該係 'coolwarm'（PDF 只見到 cmap='c…，所以呢點係推斷）。

    14. Semi-Structured Data（programming 唔考）

    呢部分同 Week 9 Section 最尾一樣，重溫重點即可。

    Data typeStructureExamplesCharacteristics
    StructuredRigid schema, fixed formatSQL databases, CSV files, Excel spreadsheetsPre-defined schema, tabular format, consistent structure
    Semi-structuredFlexible schema, self-describingXML, JSON, YAML, NoSQL databasesSchema is embedded in data, hierarchical, flexible structure
    UnstructuredNo predefined structureText documents, images, videos, audio filesNo organized schema, difficult to parse programmatically

    點解 XML 同 JSON 係 semi-structured：tag / key 名本身描述咗 data（self-describing），而且同一 collection 入面唔同 records 可以有唔同 structure —— 例如 Alice 有 grades（math、science），Bob 冇 grades 但有 attendance。CSV 就做唔到，每行一定要同一組 columns。

    <students>
  <student id="101">
    <name>Alice</name>
    <grades><math>A</math><science>B+</science></grades>
  </student>
  <student id="102">
    <name>Bob</name>
    <!-- Different structure allowed -->
    <attendance>95%</attendance>
  </student>
</students>

{"students": [
   {"id": 101, "name": "Alice", "grades": {"math": "A", "science": "B+"}},
   {"id": 102, "name": "Bob", "attendance": "95%"}
]}
    Format幾時用
    XML需要 strong schema validation 同 data integrity（用 .xsd XML schema definition 檢查 conformance，睇 .xsd 就知所有 tags 同 tree structure，例如 data.gov.hk 嘅 special traffic news）；document-oriented data；enterprise systems 要 standardized data exchange；需要 rich metadata 同 namespaces
    JSONWeb APIs / web services；application configuration files；mobile app development；real-time data exchange
    CSVSpreadsheet / simple tabular data；quick analysis 同 prototyping；systems 之間 data migration；non-technical users 要睇 / 改

    講義仲有兩個 parsing 例子（唔考 programming）：

    • XML：xml.etree.ElementTree —— ET.parse() → getroot()；root.tag、root.attrib；for child in root 遍歷 children；root.findall('country')、country.get('name')（attribute）、country.find('gdppc').text（child element 文字）。CountryData.xml 有 3 個 countries（Liechtenstein 141100、Singapore 59900、Panama 13600），平均 GDP per capita = 71533.33。
    • JSON：用 requests.get(url, params=…, headers=…) call OpenStreetMap Nominatim geocoder API（要設 User-Agent header），response.raise_for_status() 檢查錯誤，response.json() parse 成 Python list / dict，再攞 results[0]["lat"]、["lon"]（HSUHK ≈ 22.377, 114.213）。

    自我測驗 Self-test

    Q1. Groupby 嘅三個步驟係乜？print(df.groupby('type')) 會顯示乜？

    Split（按 grouper 分組）→ Apply（每組獨立套 function）→ Combine（合併結果）。直接 print 只會顯示 <DataFrameGroupBy object at 0x…>，因為 groupby object 只係 (key, sub-DataFrame) tuples 嘅 collection，未套任何 function。要用 get_group('a') 或者 .mean() 等先有結果。

    Q2. df = pd.DataFrame({'g':['x','x','y','x'], 'v':[1, np.nan, 3, np.nan]})。寫出 df.groupby('g').count() 同 df.groupby('g').size() 嘅結果。

    count()（DataFrame）：x → v = 1，y → v = 1（只數 non-NA）。size()（Series）：x → 3，y → 1（數總行數，包 NaN）。x 組 v 有 3 − 1 = 2 個 missing，y 組有 0 個。可執行寫法：g = df.groupby('g'); g.count().rsub(g.size(), axis=0)；唔好直接 Series − DataFrame，會按 columns 對齊。

    Q3. 以下三句邊句最快？點解？(a) df.groupby('quarter').mean(numeric_only=True)['TEMP'] (b) df[['TEMP','quarter']].groupby('quarter').mean() (c) df.groupby('quarter')['TEMP'].mean()

    (c) 最快（956 μs），其次 (b)（1.59 ms），(a) 最慢（6.09 ms）。(a) 先對所有 numeric columns 計 mean 先揀 TEMP，浪費大量計算；(b) 要先 copy 一個 sub-DataFrame；(c) group 完只對 TEMP 一個 column 計，又短又快（group → selection → function）。

    Q4. air_quality[['PM2.5']].groupby(by='month').mean() 有咩問題？點改？

    Caller DataFrame 只有 PM2.5，冇 grouper column month → KeyError。要包含 grouper：air_quality[['PM2.5','month']].groupby(by='month').mean()，或者 air_quality.groupby(by='month')[['PM2.5']].mean()。

    Q5. 寫一句 groupby：按 station 分組，PM2.5 計 mean 同 max，RAIN 計 sum，然後將 RAIN 改名做 'Total Rain'。

    air_quality.groupby(by='station').agg({'PM2.5': ['mean', 'max'], 'RAIN': 'sum'}).rename(columns={'RAIN': 'Total Rain'})。唔同 columns 用唔同 functions → dict；PM2.5 要多個 functions → dict value 用 list。

    Q6. 點解 .agg({'wd': 'mode'}) 唔得？有咩兩個解決方法？

    字串 dispatch 到 SeriesGroupBy，但佢冇 mode method，所以 AttributeError。唔係 Series return 一概無效。方法：(1) 傳 pd.Series.mode callable（注意多值 / version）；(2) scalar policy lambda s: s.mode().iloc[0] if not s.mode().empty else np.nan（ties 揀 sorted 第一個，all-null 回 NaN）。

    Q7. by=['quarter','TEMP_category'] 同 by=['TEMP_category','quarter'] 有乜分別？

    數值一樣（同一啲組合），但 hierarchy 唔同：前者先按 quarter 分（外層 index），每個 quarter 入面再按 TEMP_category 分；後者外層係 TEMP_category，內層係 quarter。Output 嘅 MultiIndex 次序同排列會唔同。

    Q8. 寫出 pivot_table statement 產生以下 output：index 係 studytime；columns 頂層係 mean 同 max，中層係 score，底層係 no / yes；最底有一行 Total。

    pd.pivot_table(student, index='studytime', columns='internet', values='score', aggfunc=['mean', 'max'], margins=True, margins_name='Total')。Function 名喺頂層 → aggfunc 係 list；no / yes 係 internet 嘅值 → columns；Total → margins + margins_name。

    Q9. 小例子：F 有 scores 12（yes）、8（no）、10（yes）；M 有 9（no）、14（yes）、16（yes）。pivot_table(values='score', index='sex', columns='internet', margins=True) 嘅 F 行 All 係幾多？點解唔係 9.5？

    F 行 All = (12 + 8 + 10) / 3 = 10。Margins 用原始 data 重新計 mean；9.5 係錯誤咁將兩格（no = 8、yes = 11）直接平均，冇考慮 yes 有 2 人、no 得 1 人。

    Q10. Groupby 同 pivot table 最大分別係乜？student.pivot_table(values='score', index='sex', columns='internet') 用 groupby 點寫？

    Groupby 嘅 groups 永遠只喺 index；pivot table 可以同時將 groups 放 index 同 columns（2D grouping），而且有 fill_value、margins。等價 groupby：student.groupby(['sex','internet'])['score'].mean().unstack()。

    Q11. 一個 dataset 每筆 record 嘅欄位都唔同（有啲有 grades，有啲只有 attendance），要用喺 web API。應該用 CSV、XML 定 JSON？佢屬於邊類 data？

    JSON（web APIs、real-time exchange）。佢係 semi-structured data：flexible、self-describing schema，hierarchical，唔同 records 可以有唔同 structure。CSV 要固定 columns，唔適合。

    一頁總結 Cheat sheet

    ⭐ 考前速記
    • EDA types：summary statistics（aggregating、sampling、correlation、groupby、pivot table）+ visualization。
    • Groupby = split → apply → combine；grouper 用 categorical features；df.groupby(by=…) → DataFrameGroupBy（(key, sub-df) tuples）。
    • by：label / list of labels / function（作用於 index）/ dict 或 Series（用 VALUES 分組）。
    • Methods：get_group('a')（= df[df['type']=='a']）；groups.keys()；first() / last()（按年 group 檢查 missing / 不一致，例如 2014 第一筆係 01:00）；count() non-NA（DataFrame）vs size() 全部行數（Series）。
    • groupby().mean()：output 唔包 grouper（變 index），套落所有 non-grouper columns；有非數值 columns 加 numeric_only=True。
    • Column-label grouper 要喺 caller column / 有效 index level；external aligned Series / index function 不受呢個限制。只得 grouper 都可 size()；aggregate measure 先要保留該 measure。
    • 速度：Group → Selection → Function df.groupby('q')['TEMP'].mean()（956 μs）> Selection → Group → Function（1.59 ms）> Group → Function → Selection（6.09 ms）。
    • agg(max_min) / agg(lambda c: c.max()-c.min())；agg([list]) 所有 columns 同一組；agg({dict}) 每 column 唔同；pandas name string 加引號，built-in / 自訂 callable 本身都唔加。
    • .rename(columns={'old':'new'})；長 chain 用 \ 換行。
    • Multi-level：by=['quarter','TEMP_category']，次序 = hierarchy → MultiIndex。
    • 'mode' string dispatch 失敗因 SeriesGroupBy 冇 mode method；可傳 pd.Series.mode（注意 ties），或 scalar lambda s: s.mode().iloc[0] if not s.mode().empty else np.nan。
    • Pivot table：groups 可以喺 index 同 columns；pd.pivot_table(df, values=, index=, columns=, aggfunc='mean', fill_value=, margins=False, margins_name='All') 或 df.pivot_table(…)。
    • 冇 samples 嘅組合 → NaN → fill_value=-999；margins=True 用原始 data 計 overall（唔係格仔平均）。
    • 反推 statement：左邊 → index；頂部 group 值 → columns；data column 名 → values；function 名 / <lambda> → aggfunc（list 或 dict）；冇 function 名 → mean；All → margins。
    • Pivot ≈ groupby([a,b])[v].mean().unstack()。
    • Visualization：tables 難睇 pattern → heatmap / bar chart（sns.catplot、sns.heatmap）揭示 trends、outliers、relationships（下週）。
    • Structured（rigid）/ Semi-structured（XML、JSON，self-describing、hierarchical）/ Unstructured；XML → schema validation（.xsd）、enterprise；JSON → web API、config、mobile、real-time；CSV → tabular、quick analysis、non-technical users。
