    1. Visualization libraries 概覽

    Library特點適合
    MatplotlibComprehensive；static、animated 或 interactive plots；highly customizable，但寫法 complicated要逐樣微調嘅圖；其他 library 嘅底層
    Pandas（df.plot()）Behind the scenes 用 Matplotlib；good for quick checks；畫唔到 sophisticated、靚嘅圖EDA 時快速睇一眼
    Seaborn（Statistical Data Visualization）Build on top of Matplotlib，同 Pandas data structures 緊密整合；pretty、informative統計圖：分佈、類別比較、相關
    PlotlyInteractive visualizations / dashboard可 hover、zoom、animation 嘅圖
    💡 直覺理解

    四者係「由低層到高層」：Matplotlib 好似畫布同畫筆，乜都畫到但要自己逐筆畫；Seaborn 係「統計圖模板」，俾 DataFrame 同 column 名佢就自動計 mean、CI、分佈；Plotly 就係「會郁、可以互動」嘅圖。Seaborn 底層仍然係 Matplotlib，所以 plt.figure(figsize=…) 呢類 Matplotlib 指令都可以同 seaborn 一齊用（§6 heatmap 就係咁）。

    2. Seaborn：figure-level vs axes-level，同揀圖原則

    Seaborn 係 Python data visualization library，based on matplotlib，提供 high-level interface 畫 attractive and informative statistical graphics。用法：import seaborn as sns，然後 sns.xxxplot()。

    Seaborn functions 分兩層（optional knowledge）：

    • Axes-level functions：將 data 畫落一個 matplotlib.pyplot.Axes object，return 值就係嗰個 Axes。
    • Figure-level functions：透過一個 seaborn object（通常係 FacetGrid）管理成個 figure。每個 module 有一個 figure-level function，作為佢下面各個 axes-level functions 嘅統一 interface。
    Figure-level（module）對應 axes-level functions
    relplot()（relational）scatterplot、lineplot
    displot()（distributions）histplot、kdeplot、ecdfplot、rugplot
    catplot()（categorical）stripplot、swarmplot、boxplot、violinplot、pointplot、barplot

    （上表係 notebook 第一張圖 “Plotting functions” 嘅內容。）Figure-level function 用 kind= 揀用邊個 axes-level function，例如 sns.catplot(..., kind='box') ≈ sns.boxplot(...)，但前者仲可以用 col / row 開 sub-plots。

    ⭐ 考試重點：按 feature 類型揀圖（slide 原文整理）
    情況目的圖 / function
    1 個 numerical睇分佈Histogram、KDE plot：displot()；Boxplot：catplot(kind='box')
    1 個 categorical睇各類別數量Bar (count) plot：catplot(kind='count')
    2 個 numerical關係 / 相關Scatter：relplot() / pairplot() / jointplot()；Correlation：heatmap()

    3. 一個 numerical feature：displot() / histplot()

    3.1 Figure-level vs axes-level 嘅 return type（optional）

    兩者畫出嚟差唔多，但 return 嘅 object 唔同，所以改 axis labels、title、legend 嘅 method 唔同：

    # Figure-level：displot() 回傳 FacetGrid
g = sns.displot(air_quality, x='TEMP')
g.set_axis_labels("Temperature", "counts")   # FacetGrid 用 set_axis_labels()

# Axes-level：histplot() 回傳 matplotlib Axes
ax = sns.histplot(air_quality, x='TEMP')
ax.set_xlabel('temperature')                  # Axes 用 set_xlabel() / set_ylabel()
ax.set_ylabel('counts')
    ⚠️ 易混淆

    g.set_xlabel() 喺 FacetGrid 上面係冇嘅（會 AttributeError）；ax.set_axis_labels() 喺 Axes 上面都冇。記法：figure-level → set_axis_labels；axes-level → set_xlabel / set_ylabel。Notebook output 見到 <seaborn.axisgrid.FacetGrid at 0x…> 就知係 figure-level；見到 <Axes: > 或 Text(0, 0.5, 'counts') 就係 axes-level。

    3.2 kind：hist（default）、kde、ecdf

    • kind='hist'（default）：histogram，每個 bin 嘅 counts。
    • kind='kde'：KDE plot（Kernel Density Estimation）—— 將 continuous variable 嘅 probability density function 畫成一條平滑曲線；比 histogram 冇咁亂，通常更易睇。（Notebook 寫成 kind = 'ked'，係 typo，正確係 'kde'。）
    • kind='ecdf'：ECDF（Empirical Cumulative Distribution Function）—— 每個值 \(x\) 對應「\(\le x\) 嘅 data points 佔幾多比例」。
    $$ \hat{F}_n(x) = \frac{\#\{\, i : x_i \le x \,\}}{n} $$
    sns.displot(air_quality, x='TEMP', kind='kde')    # 平滑 density 曲線
sns.displot(air_quality, x='TEMP', kind='ecdf')   # cumulative distribution，由 0 升到 1
    💡 小例子：ECDF

    Data = 2, 5, 5, 8（\(n = 4\)）。\(\hat{F}(1) = 0\)，\(\hat{F}(2) = 1/4\)，\(\hat{F}(5) = 3/4\)（2、5、5 三個 \(\le 5\)），\(\hat{F}(8) = 1\)。ECDF 係階梯形，永遠唔會跌；中位數就係 ECDF 過 0.5 嘅位置。好處係唔使揀 bin 寬度（histogram 要揀）亦唔使揀 bandwidth（KDE 要揀）。

    3.3 調整圖嘅 style

    • 大小：用 height 同 aspect；冇 width 呢個參數，\(\text{width} = \text{aspect} \times \text{height}\)，default aspect = 1.0。
    • 顏色：color='green'。
    • Theme：sns.set_theme() 轉做 seaborn default theme（有 grid，較 fashionable）；可指定 style，例如 sns.set_theme(style="whitegrid")，其他："darkgrid"、"ticks"、"dark"、"white"。sns.set_theme(font_scale=1) 調字體大細。
    sns.displot(air_quality, x='TEMP', height=3, aspect=2, color='green')   # 高 3、闊 = 2 × 3 = 6
sns.set_theme()                     # 之後所有圖都用 seaborn default theme

    Exam 留意 set_theme() 係全局設定，會影響之後所有圖，唔係淨係下一張。

    Q1：用 hue 顯示 quarters —— numerical vs categorical hue

    # 第一次：quarter 係 int（1, 2, 3, 4）
sns.relplot(data=air_quality, x='TEMP', y='PRES', hue='quarter', kind='scatter')

# 將 1, 2, 3, 4 map 做 'one', 'two', 'three', 'four'（Week 9 嘅 map）

    兩張圖嘅分別：quarter 係數字時，seaborn 當佢係 numeric hue，用一條由淺到深嘅 sequential palette（1 最淺粉紅、4 最深紫黑），好難分清邊點屬邊個 quarter；map 做字串之後，seaborn 當佢係 categorical，用對比鮮明嘅 qualitative palette（one 藍、two 橙、three 綠、four 紅），一眼睇得出 Q1（冬）喺左上（低溫高壓）、Q3（夏）喺右下。

    ⭐ 考試重點：hue 嘅顏色規則

    Hue column 係 numeric → 連續漸變色（暗示大小次序）；係 categorical / string → 每類一個獨立顏色。如果 category 只係用數字做 code（例如 quarter 1–4、station ID），想每類一個明顯顏色，就要先轉做 string 或 category dtype。Notebook 原文將呢個現象講成「Pandas will recognise the categorical values to be either rankable or not rankable」—— 實際上係 seaborn 按 hue 嘅 dtype 揀 palette：numeric 用 sequential，非 numeric 用 qualitative。

    5. Categorical features：catplot()

    catplot() 係畫 categorical plots 嘅 interface，用 kind 揀底層 axes-level function，顯示一個 numerical 同一個或多個 categorical variables 嘅關係。慣例：categorical feature 放 x 軸，numerical feature 放 y 軸（掉轉放就變橫向圖）。

    ⭐ 考試重點：catplot 嘅 kinds
    類別kind=Axes-level顯示咩
    一個 categorical'count'countplot()每個類別有幾多 rows
    Categorical estimate（summary statistics）'point'pointplot()每類嘅估計值（點）+ confidence interval
    'bar'barplot()每類嘅 mean（或其他 estimator）+ confidence interval
    Categorical scatterplots'strip'（default）stripplot()所有 individual points，可能重疊
    'swarm'swarmplot()所有 individual points，唔重疊（散開排）
    Categorical distribution'box'boxplot()Q1、median、Q3、whiskers、outliers
    'violin'violinplot()分佈曲線（KDE 形狀）
    'boxen'boxenplot()更多 percentiles，睇 tails

    chart = sns.catplot(data=air_quality, x='PM2.5_cat', kind='count', height=4, aspect=2)
chart.set_xticklabels(rotation=45)    # x 軸 label 太長就打斜

    5.2 Summary statistic plots：relplot(kind='line') / catplot(kind='bar')

    想睇「每個類別嘅 numerical feature 嘅某個 summary statistic（例如 mean、median）」：categorical 放 x、numerical 放 y，kind='line' 或 'bar'，咁每個 x category 只得一個 y 值 = 該類嘅 statistic（default 係 mean），可以用 estimator= 改。

sns.relplot(data=air_quality, x='wd', y='PM2.5', kind='line')                  # 每個風向嘅 PM2.5 mean
sns.relplot(data=air_quality, x='quarter', y='RAIN', kind='line', estimator=sum) # 改計 sum：每季總雨量

air_quality['wd'] = air_quality['wd'].str[0]      # 'NNE' → 'N'：16 個風向簡化成 N/E/S/W
chart = sns.catplot(data=air_quality, x='wd', y='PM2.5', kind='bar')   # x = categorical，y = numerical 嘅 summary
chart.set_xticklabels(rotation=45)

    Line plot 個圖顯示：N、W 風時 PM2.5 mean 約 69–70，E 風約 105，S 風約 91，線旁邊有淺色帶 = confidence interval。即係東風、南風時污染較嚴重（北京東南面係工業區 / 平原，西北風帶嚟較乾淨空氣）。

    catplot(x='wd', y='PM2.5', kind='bar') 嘅 bar 高度其實就係 air_quality.groupby('wd')['PM2.5'].mean()；estimator=sum 就等於 .sum()。即係 Week 10 groupby 嘅結果畫成圖，再加 error bar。

    ⚠️ 常見錯誤

    (1) Line plot 會用直線連住相鄰 categories，暗示佢哋之間有次序 / 連續變化。wd 係 nominal（N、W、E、S 冇大小次序），x 軸次序只係 data 出現次序，所以 line 嘅升跌形狀冇意義 —— 比較 nominal 類別用 bar 較合適；line 適合有次序嘅 x（quarter、month、年份）。(2) Notebook 嘅 line plot 已經只見 N/W/E/S，即係 .str[0] 嗰格喺佢之前執行咗（notebook 有 out-of-order execution），照次序重跑嘅話會見到 16 個風向。

    5.3 Strip plots vs swarm plots（categorical scatterplots）

    sns.catplot(data=iris_flower, y='sepal.length', x='variety', kind='swarm', hue='variety', aspect=1)
sns.catplot(data=air_quality, kind='strip', x='PM2.5', y='PM2.5_cat', height=4, aspect=2)   # strip 係 default kind
    • Swarm：每個點都畫出嚟，自動左右推開避免重疊，睇到每類嘅分佈形狀同點數。適合細 data（iris 150 rows）；data 太大（air_quality 九萬幾行）會好慢兼排唔落。
    • Strip：點沿軸排，加少少 jitter，但可能重疊；大 data 都畫到。

    5.4 Box、violin、boxen plots（statistical summaries）

    sns.catplot(data=air_quality, x='PM2.5', kind='box', aspect=1)     # 只有一個 numerical feature 都得

    呢張 box plot 顯示 PM2.5 嚴重 right-skewed：box（Q1 至 Q3）大約 20–115，median 約 60，右邊 whisker 去到約 255，之後有大量 outlier 圓點一路去到 800+。

    ⚠️ Box plot 嘅 whiskers 唔一定係 min / max

    Notebook 寫 boxplot 顯示 “min, Q1, median, Q3, and max”。更準確：seaborn / matplotlib default 嘅 whisker 只伸到最遠一個仍喺 \(1.5 \times \text{IQR}\) 範圍內嘅點，超出範圍嘅點逐個畫做 outliers。所以有 outliers 時，whisker 末端唔係 max（上面例子：whisker 約 255，max 約 820）；真正嘅 max / min 係最遠嗰粒 outlier（冇 outlier 時先等於 whisker 末端）。

    $$ \text{IQR} = Q_3 - Q_1,\qquad \text{upper fence} = Q_3 + 1.5\,\text{IQR},\qquad \text{lower fence} = Q_1 - 1.5\,\text{IQR} $$

    例：\(Q_1 = 20\)、\(Q_3 = 115\) → IQR = 95 → upper fence = 115 + 142.5 = 257.5，同圖中 whisker 約 255 吻合（whisker 停喺 fence 以內最大嘅實際數據點）。呢個就係 Week 7 outliers 嘅 IQR method。

    Q2：一張圖顯示五個溫度類別嘅 PM2.5 min、max、median、outliers

    # 答案：box plot，categorical 放一條軸、numerical 放另一條軸
sns.catplot(data=air_quality, y='TEMP_category', x='PM2.5', kind='box', aspect=1.5)

    圖中五個橫向 box（Very Cold 喺頂，Very Hot 喺底）：Very Cold 嘅 box 最闊、whisker 最長（到約 350），outliers 去到 800+；越熱 box 越窄、whisker 越短（Hot / Very Hot 約 210）。即係天氣越冷，PM2.5 越高、越波動（冬天燒煤取暖 + 逆溫層）。

    sns.catplot(data=air_quality, y='TEMP_category', x='PM2.5', kind='violin', aspect=1.5)
sns.catplot(data=air_quality, y='TEMP_category', x='PM2.5', kind='boxen', k_depth=3, height=4, aspect=1.5)
    • Violin：每類畫一個左右對稱嘅 KDE 曲線（形似小提琴），睇到分佈形狀（例如 bimodal），box plot 睇唔到。
    • Boxen（optional）：一層層 boxes 代表唔同 percentiles（25%、50%、75%、95%…），比 box plot 更詳細咁顯示 tails，適合大 data。k_depth 控制層數：'full'（畫晒所有可能 boxes）、'trustworthy'（只畫統計上可靠嘅 boxes）、或整數（例如 k_depth=3 → notebook 話會畫 5 個 boxes）。
    💡 點揀 box / violin / boxen？

    要數字化嘅 summary（median、quartiles、outliers）→ box；要睇分佈形狀（幾個峰、偏向邊）→ violin；data 好大、想睇尾部細節而唔想幾千粒 outliers 擠埋一齊 → boxen。

    5.5 用 col 同 row 開 sub-plots

    一個 numerical feature 嘅分佈配多過一個 categorical feature：col='feature A' 按 A 開直行 sub-plots；row='feature B' 按 B 開橫行 sub-plots。

    g = sns.displot(data=air_quality, x='PM2.5', col='quarter', height=3, col_wrap=2)   # 4 個 quarter，每行 2 張
g.set_axis_labels("PM2.5")

# col × row 格網：每格 = 一個 (wd, quarter) 組合；sharex=False 令每格都顯示自己嘅 x 軸
sns.displot(data=air_quality, x='PM2.5', col='wd', row='quarter', facet_kws={'sharex': False})

    col_wrap=2：每行最多 2 張，超出就換行（只可配 col，唔可以同 row 一齊用）。4 個 wd × 4 個 quarter = 16 格。

    ⭐ 考試重點：「加多一個 feature」嘅方法
    • 加 categorical feature：hue（同一張圖不同顏色）、col / row（分開 sub-plots）。
    • 加 numerical feature：scatter plot 嘅 size（點大細），或者顏色漸變 —— seaborn 用 numeric 嘅 hue='TEMP'，Plotly 先用 color='TEMP'。Seaborn 嘅 color= 只收一個固定顏色（例如 'green'），color='TEMP' 會出 invalid colour error。
    • 睇圖反推：有 legend 列出類別 → hue；有幾格標題如 quarter = 1 → col / row；點有大有細 → size。

    6. 多過兩個 numerical features：pairplot、jointplot、heatmap

    6.1 pairplot()

    pairplot() 為所有 numerical features 兩兩畫 scatter plots（對角線畫每個 feature 自己嘅分佈）。sns.pairplot(data=air_quality) 會為成個 dataset 嘅 numerical columns 畫，notebook 叫你唔好跑（太多 columns，好耗時）—— 先揀幾個 columns：

    sns.pairplot(data=air_quality[['TEMP', 'PRES', 'WSPM']])                       # 3 × 3 格

    ⚠️ mag3 唔係 normalization，而且有缺陷

    Notebook comment 話 “normalize and amplify the differences in magnitude”。但 \(2(x - \bar{x})^2\) 係平方離差：佢放大咗同 mean 嘅距離，卻失去方向。由 output 反推 mean 約 5.88（Magnitude 5.8 → mag3 ≈ 0.0136，6.0 → 0.0276，6.2 → 0.2016）。問題：一個細過 mean 嘅地震（例如 5.5）會得到 \(2(5.5-5.88)^2 \approx 0.29\)，比 6.2 級嘅 0.20 仲大，泡泡反而更大。如果想大地震 = 大泡泡兼放大差距，應該用單調遞增嘅 transform，例如 \((x - x_{\min})^2\)、Min-Max scaling 後再平方，或者 \(10^{x}\)（magnitude 本身係 log scale）。呢度圖仍然用 color='Magnitude' 正確顯示大小，size 嘅意義就要小心解讀。

    Q1. Seaborn 三個 figure-level functions 係乜？各自下面有咩 axes-level functions？

    Q5. 為以下情況建議圖同 seaborn / plotly statement：(a) 五個 TEMP_category 嘅 PM2.5 median、quartiles 同 outliers；(b) 每個 station 有幾多 records；(c) 每月平均 PM2.5 嘅趨勢；(d) TEMP、PRES、DEWP、WSPM 兩兩關係。

    Q6. Strip plot 同 swarm plot 有咩分別？air_quality（約 9.6 萬行）應該揀邊個？

    兩者都畫每個 individual data point。Strip（catplot 嘅 default kind）點可以重疊；swarm 自動推開點，唔重疊。Swarm 喺大 data 會極慢而且排唔落，所以 air_quality 用 strip（或者乾脆用 box / violin / boxen 睇分佈）；swarm 適合細 data 例如 iris。

    Q7. 一個 box plot：\(Q_1 = 30\)、median = 55、\(Q_3 = 90\)，最大值 = 400。Whisker 上端最多去到邊？400 會點顯示？

    IQR = 90 − 30 = 60；upper fence = 90 + 1.5 × 60 = 180。上 whisker 去到 ≤ 180 嘅最大實際數據點；400 > 180，所以畫成獨立 outlier 點。即係 whisker 末端唔等於 max。

    Q8. 讀以下 statement，講出圖入面用咗咩 features、各以咩方式顯示：px.scatter(data, x="gdpPercap", y="lifeExp", size="pop", color='continent', hover_name="country", animation_frame="year")

    x 軸 = GDP per capita；y 軸 = life expectancy；泡泡大小 = population；顏色 = continent（categorical，每洲一色）；滑鼠 hover 標題 = country；animation（slider / 播放）= year，每年一個 frame。共 6 個 features。

    Q9. Notebook 話 TEMP vs PRES scatter 顯示 “strong inverse relationship between temperature and wind speed”。呢句有咩問題？

    圖嘅 y 軸係 PRES（pressure），唔係 wind speed。Correlation matrix：TEMP–PRES = −0.82（strong inverse），TEMP–WSPM = 0.015（幾乎無關）。正確結論係 temperature 同 pressure 強烈反向相關。

    Q10. 點解要用 px.bar_polar 而唔係 px.bar 顯示 16 個風向嘅平均 PM2.5？category_orders 有咩用？

    風向係 circular data：普通 bar 會按字母排（E、ENE、ESE、N…），相鄰方向被拆散，睇唔到空間 pattern。Polar bar 用 theta='wd' 放返指南針位置、r='PM2.5' 做長度，一眼睇到東 / 東南風最污染、西北風最乾淨。category_orders={'wd': direction_order} 確保方向按 N → NNE → … → NNW 順時針排。

    Q11. 由 month 整 season（Spring 3–5、Summer 6–8、Autumn 9–11、Winter 12–2），然後用 season 做 hue 畫 PM2.5、TEMP、WSPM 嘅 pairplot。

    season_map = {12:'Winter', 1:'Winter', 2:'Winter', 3:'Spring', 4:'Spring', 5:'Spring', 6:'Summer', 7:'Summer', 8:'Summer', 9:'Autumn', 10:'Autumn', 11:'Autumn'}；df['season'] = df['month'].map(season_map)；sns.pairplot(df[['PM2.5','TEMP','WSPM','season']], hue='season')。注意 hue column 要包含喺傳入嘅 DataFrame 入面。結論：冬天 PM2.5 最高、夏天最低；風速越高 PM2.5 越低。

    一頁總結 Cheat sheet

    ⭐ 考前速記
    • 考試要求：識睇圖講出用咗咩 features、識為 dataset 建議合適嘅圖；唔使死記 syntax。
    • Libraries：Matplotlib（底層、customizable、complicated）/ Pandas（用 Matplotlib，quick check）/ Seaborn（build on Matplotlib + Pandas，統計圖，pretty & informative）/ Plotly（interactive、dashboard）。
    • Seaborn figure-level：relplot（scatter、line）、displot（hist、kde、ecdf、rug）、catplot（strip、swarm、box、violin、boxen、point、bar、count）；用 kind= 揀。
    • Figure-level → FacetGrid → g.set_axis_labels()；axes-level → Axes → ax.set_xlabel()。
    • height × aspect = width（冇 width 參數，aspect default 1）；color='green'（固定一個顏色，唔係 map column）；sns.set_theme(style="whitegrid"/"darkgrid"/"ticks"/"dark"/"white") 係全局。
    • 1 numerical：hist / kde（平滑 density）/ ecdf（\(\le x\) 嘅比例）/ box。1 categorical：count。
    • 2 numerical：scatter（relplot）、pairplot（全部兩兩，對角線 = 分佈）、jointplot（一對 + marginal distributions）、heatmap(df.corr(numeric_only=True), cmap='coolwarm')。
    • Num + cat：bar / point = summary（default mean + CI，estimator=sum 可改）；strip（default，重疊）/ swarm（唔重疊，細 data）；box（quartiles + 1.5 IQR whiskers + outliers）/ violin（分佈形狀）/ boxen（多 percentiles、tails，k_depth）。
    • 2 categorical：count plot，一個 x，另一個 hue 或 col。
    • 加 features：categorical → hue / col / row（col_wrap、facet_kws={'sharex': False}）；numerical → size 或 numeric hue（seaborn）/ color（Plotly）。
    • Hue 係 numeric → sequential 漸變；string / category → 每類一色 → 數字 code 要先 map 成文字。
    • Line 連接 categories 會暗示次序：nominal 類別（wd）用 bar；有序 x（月、年）先用 line。
    • Heatmap 結論：PM2.5 同 PM10 / CO / NO2 / SO2 正相關（combustion）；TEMP–DEWP +0.82；TEMP–PRES −0.82。Redundant derived features（days vs weeks = 1.0）唔係發現。Correlation ≠ causation。
    • Plotly Express：import plotly.express as px；比 graph_objects 少 5–100 倍 code；return go.Figure；fig.show()。
    • px.scatter(x, y, color, size, symbol, hover_name, size_max, width, height, animation_frame)；px.line(y=[list]) 多條線。
    • px.sunburst(path=[大→細], values=)：hierarchical、part-to-whole；px.bar_polar(r=, theta=, category_orders=)：方向 / circular data。
    • Maps：lat + lon 或 ISO alpha codes；px.choropleth(locations=, color=)、px.density_map(lat, lon, z)、px.scatter_geo(locations= 或 lat/lon, size, animation_frame)。
    • Animated：animation_frame='year'（或 season 等 layers）。Gapminder 經典：x = gdpPercap、y = lifeExp、size = pop、color = continent、hover_name = country。
