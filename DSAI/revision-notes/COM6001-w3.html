    Dict 係 iterable，可以 loop 佢嘅 keys、values 或 items。Python 3.7 起 dict 保留 insertion order；之前版本係 unordered (可以 loop，但次序冇保證)。Notebook 用嘅係 Python 3.10。

# the 'key' is marks and its value is 100

    3.4 while loops

    Condition 為 True 就一直 loop。要自己 increment / decrement iterator，否則 loop 永遠唔會停 (infinite loop)。

    num = 0
while (num < 10):
    num += 1          # 忘記呢句 → while loop never ends
    print(num)        # 1 … 10

# 緊接住再行：
while (num in range(0, 10)):   # 此時 num == 10，唔喺 range(0,10) 入面 → 一次都唔行
    num = num + 1
print(num)            # 10
    ⚠️ 易錯位

    第一個 while 印 1 至 10 (唔係 0 至 9)：因為先 += 1 再 print；最後一輪 num = 9 < 10 成立 → 變 10 → 印 10。第二個 while 因為 num 已經係 10，condition False，所以 body 唔執行，只印 10。

    5. Recursion & Debugging

    5.1 Recursion

    Recursion：function call 自己，用嚟解決可以拆成較細、相似 subproblems 嘅問題。

    • 一定要有 base case，防止 infinite recursion，令 recursive calls 最終終止。
    • 某些問題用 recursion 更優雅易明，但對大 input 可能用更多 memory、更慢 (相比 iterative)。

    例子：binary search — 喺已排序 list 搵 target：睇中間 mid，等於就 return；細過 target 就去右半邊搵；大過就去左半邊搵。

    def binary_search(nums, target, left=None, right=None):
    if left is None:
        left = 0
    if right is None:
        right = len(nums) - 1
    if left >= right:            # ← base case (有 bug！)
        return -1
    mid = left + (right - left) // 2
    if nums[mid] == target:
        return mid
    elif nums[mid] < target:
        return binary_search(nums, target, mid + 1, right)
    else:
        return binary_search(nums, target, left, mid - 1)

my_list = [1, 2, 3, 4, 5]
binary_search(my_list, 3)   # 2 ✓
binary_search(my_list, 5)   # -1 ✗ 應該係 4

    5.2 Debugging

    Debugging = 找出並修正 errors / bugs。Python 常用工具：

    • Print statements：喺不同位置 print variables 嘅值。
    • Exception handling：try-except 捕捉 exceptions，幫助定位錯誤來源。
    • Logging：用 logging module 記錄訊息同事件。
    • Debuggers：IDE / command-line debugger，set breakpoints、逐步執行、inspect variables。
    # 5.2.1 用 print debug
def binary_search(nums, target, left=None, right=None):
    if left is None: left = 0
    if right is None: right = len(nums) - 1
    print(f"left = {left}, right = {right} -> {nums[left:right + 1]}")
    if left >= right:
        print("break because left >= right")
        return -1
    mid = left + (right - left) // 2
    if nums[mid] == target:
        return mid
    elif nums[mid] < target:
        return binary_search(nums, target, mid + 1, right)
    else:
        return binary_search(nums, target, left, mid - 1)

    6. Anonymous (lambda) functions

    先分清：statements 包括 expressions；expressions 一定會產生一個值。例：x = 1 係 statement (assignment)，x == 1 係 expression (產生 True/False)。

    Lambda function：細小、anonymous (冇名) 嘅 function，可以有多個 parameters 但只有一個 expression，又叫 lambda expression。

    lambda arguments: expression
    (lambda x, y: x - y)(3, 5)     # -2   ← 直接喺後面加 (args) call
sum_up = lambda x, y: x + y    # sum_up 只係成個 lambda body 嘅 "nickname"
sum_up(35, 5)                  # 40
(lambda x, y: x + y)(35, 5)    # 40   冇 nickname 都可以，用 () 包住 body

def remove_1st(x):             # 等價 full function
    return x[1:]
remove_1st_lambda = lambda x: x[1:]
remove_1st([1, 2, 3, 4, 5])          # [2, 3, 4, 5]
remove_1st_lambda(" Lecture 03")     # 'Lecture 03'  ← 對 string 一樣 work (slicing)

    Embedded usage: lambda 作為另一個 function 嘅 input

    老師唔建議單獨用 lambda；佢主要用喺另一個 function 入面 — 作為 input parameter 或 return value。最經典：list.sort(key=...)。

    id_string = ['a3', 'b1', 'c5', 'd2']
id_string.sort()                       # ['a3', 'b1', 'c5', 'd2']  按成個 string (第一個字母) 排
id_string.sort(key=lambda x: x[1])     # ['b1', 'd2', 'a3', 'c5']  按第二個字元 (數字) 排
    💡 直覺理解

    key 係一個「將每個元素轉成排序依據」嘅 function。sort 會對每個元素 call key(x)，然後按結果排。lambda x: x[1] 即係「用第二個字元做排序依據」。

    student_dict = {"b003": "John", "a005": "Robin", "a002": "Aileen", "b001": "Mary"}

def student_sort(d):
    key_list = list(d.keys())
    key_list.sort(key=lambda x: int(x[-3:]), reverse=True)   # 按數字部分 (最後 3 位) 降序
    sorted_values = []
    for k in key_list:                 # ['a005', 'b003', 'a002', 'b001']
        sorted_values.append(d[k])
    return sorted_values

student_sort(student_dict)   # ['Robin', 'John', 'Aileen', 'Mary']

    return lambda x: x + adder

my_func(5)        # <function my_func.<locals>.<lambda>(x)>  ← 返回嘅係一個 function
my_func(5)(3)     # 8   等於 (lambda x: x + 5)(3)
    ⭐ 考試重點

    my_func(5) 返回 lambda x: x + 5 呢個 function 本身 (未執行)，所以要再加一對括號提供 x：my_func(5)(3) → 8。

    🖼️ 留意

    Notebook 中 my_func(5)(3) 嘅輸出多咗一行 “mul is 5”，但顯示嘅 function 定義冇對應 print，相信係老師舊版 cell 殘留；以 function 定義為準，結果係 8。

    7. Python packages & modules

    • Module：單一 .py 檔，包含 functions、classes、variables，可以 import 使用。
    • Package：有結構嘅 modules 集合，將相關 modules 組合埋一齊。
    • 用 import 載入：import math、import pandas as pd。
    • Python standard library 已包含好多 modules；numpy、pandas 等要另外安裝。
    • 用 modules / packages 組織 code 令程式更 readable、reusable、maintainable。

    7.1 pip commands

    pip 係 Python 嘅 package installer，用嚟 install、update、manage packages。可以喺 terminal / command prompt 用，或者喺 Jupyter 用 ! (執行 terminal command) — 但更建議用 %pip，因為佢保證裝喺 notebook 當前使用嘅 environment；!pip install 可能裝咗去另一個 environment。

    Command作用

    Q1. 以下 code 輸出咩？for i in range(1, 12, 4): print(i)

    1、5、9 (12 唔包含；下一個 13 已超出)。

    Q2. d = {"a": 1, "b": 2}。for x in d: print(x) 同 for x in d.items(): print(x) 分別印咩？

    第一個印 keys：a、b。第二個印 tuples：('a', 1)、('b', 2)。

    Q3. 計算：17 // 5、17 % 5、2 ** 4、9 / 3

    3、2、16、3.0 (/ 永遠返回 float)。

    Q4. def f(a, b=2, *args): return a + b + len(args)。f(1)、f(1, 5)、f(1, 5, 'x', 'y')、f(b=1, a=3) 各返回咩？

    f(1) = 1+2+0 = 3；f(1, 5) = 1+5+0 = 6；f(1, 5, 'x', 'y') = 1+5+2 = 8 (args = ('x','y') tuple)；f(b=1, a=3) = 3+1+0 = 4。

    Q5. 以下會印咩？點解？
    x = 10
def g(x):
    x = x * 2
    return x
y = g(x)
print(x, y)

    印 10 20。Function 入面嘅 x 係 local variable，改佢唔影響外面嘅 x (int 係 immutable)；return 值 20 assign 畀 y。

    Q6. 原本 binary_search 用 if left >= right: return -1，喺 [1,2,3,4,5] 搵 5 點解錯？點改？

    最後一次 call left = right = 4，範圍只剩 [5]，本應檢查 nums[4]，但 left >= right 成立直接 return -1。改為 if left > right:，只有範圍真正為空先 return -1。修正後返回 4。

    Q7. 寫一句 code 將 words = ['banana', 'kiwi', 'apple'] 按字串長度排序。

    words.sort(key=lambda w: len(w)) (或 key=len) → ['kiwi', 'apple', 'banana']。

    Q8. def h(n): return lambda x: x * n。h(3) 同 h(3)(4) 係咩？

    h(3) 返回一個 function (lambda x: x * 3)；h(3)(4) = 12。

    Q9. Install 同 import 有咩分別？點解喺 Jupyter 用 %pip 而唔用 !pip？

    Install = 下載 package 到電腦，每個 environment 做一次；import = 載入當前 session，每次新 session 都要做。%pip 保證裝喺 notebook 當前 kernel 嘅 environment；!pip 係行 shell command，可能裝咗去另一個 environment。

    Q10. a = 3; print(a%3==0 | a%2==0) 點解係 False？

    | (bitwise OR) 嘅 precedence 高過 ==，所以變成 a%3 == (0 | a%2) == 0 → 0 == 1 == 0 (chained comparison) → False。應該用括號或者用 or。

    一頁總結 Cheat sheet

    ⭐ 考前速記
    • pop() remove & return；append() return None — 睇 docstring 有冇 “return”。
    • Block = colon : + 一致 indentation (建議 4 spaces)；if 後一定要有 indented action。
    • = assignment vs == assertion；elif 有 condition，else 冇且必須最後。
    • Ternary：a if cond else b。
    • for item in iterable；dict 直接 loop = keys；.items() = (key, value) tuples；Python 3.7+ dict 保留 insertion order。
    • range(start, stop, step) stop 唔包含，唔係 list；while 要自己 increment。
    • / → float，// floor，% 餘數，** 次方；用 and/or/not，小心 | precedence。
    • def f(pos, kw=default, *args):；*args → tuple；return 即終止；immutable argument 喺 function 內改唔影響外面。
    • Recursion 要 base case；binary search bug：left >= right → 改 left > right。
    • Debug：print / try-except / logging / debugger (Continue, Step over, Step into, Step out)。
    • lambda args: expression；主要用作 sort(key=lambda x: ...) 或 return value；my_func(5)(3)。
    • Module = 一個 .py；package = modules 集合。%pip show/install/uninstall；Install 一次 / Import 每 session；install before import。
