    One-sample & Two-sample t-tests

    🎯 本講重點 (Learning outcomes)

    • 用 parametric test flowchart 揀啱 test：1-sample t / Z test、paired t、2-sample (independent) t、1-way ANOVA。
    • 理解點解用 t 而唔用 Z（σ 未知、n 細；t 有 heavier tails，df 越大越似 Z）。
    • One-sample t-test：寫 H0/H1、計 \( T=(\bar y-\mu_0)/(s/\sqrt n) \)、查 t-table（df = n − 1）、用 p-value 決定。
    • 識講三個等價 decision rule（T vs ppf、cdf、p-value）同 one-sided / two-sided 嘅 rejection rule。
    • 由 two-sided decision rule 推出 Confidence interval。
    • Two-sample：paired design（計差 W 再做 one-sample t）vs completely randomized design（pooled variance \( s_p \)，df = n + m − 2）。

    ⭐ 考試必溫 Top-5

    1. One-sample t：\( T = \dfrac{\bar y - \mu_0}{s/\sqrt n} \)，df = n − 1；腫瘤例 T = 2.076 > 1.833 → reject H0（p = 0.0339）。
    2. 查 t-table：n = 10、α = 5%（one-sided）→ 1.833 = t.ppf(0.95, 9)；two-sided 用 α/2。
    3. Rejection rules：μ > μ0 → T > \( t_{\alpha,n-1} \)；μ < μ0 → T < −\( t_{\alpha,n-1} \)；μ ≠ μ0 → |T| > \( t_{\alpha/2,n-1} \)。
    4. CI：\( \bar y \pm t_{\alpha/2,n-1}\, s/\sqrt n \)。
    5. Paired（\( t = \bar W/(S/\sqrt n) \)，df = 對數 − 1）vs Independent（pooled \( s_p \)，df = n + m − 2）；分辨題目屬邊種 design。

    2. Z-distribution vs t-distribution

    Slide 3 嘅圖：Normal (Z) 同 t-distribution (df = 5, 10, 30) 疊埋比較。t 都係對稱鐘形，但中間矮少少、兩邊 tails 厚啲；df 越大越貼近 Z，df = 30 已經同 Z 幾乎重疊。

    💡 直覺理解

    用 s 代替 σ 會帶多一層不確定性（s 本身都係估出嚟），所以 t 嘅 tails 厚啲，critical value 大啲——要更極端嘅證據先 reject H0。n 越大，s 越準，t 就越接近 Z（t-table 最底 ∞ 行 = Z 值：1.645、1.960、2.326、2.576）。

    3. One-sample t-test：設定

    Slide 4：「病人接受治療後，情況整體有冇改善？」

    Slide 5：

    • Situation：只有一欄數據 \( y_1, y_2, \dots, y_n \)。
    • Objective：檢查治療後腫瘤大細。Variable = 腫瘤大細嘅變化（+ve 代表腫瘤縮細）。
    • H0：Population mean ≤ 0（腫瘤增大或不變）；H1：Population mean > 0（腫瘤縮細）。
    • H0 同 H1 必須 mutually exclusive（唔重疊）同 collectively exhaustive（包晒所有可能）。
    • 例：Y = the decrease in tumor size after treatment。問：有冇證據顯示治療有用？即 test \( H_0:\mu\le 0 \) against \( H_1:\mu>0 \)。
    • 因為量度有誤差，即使治療無效，sample mean 都唔會剛好 = 0。How large is large? → 要 t-test 去判斷。
    ⚠️ 留意

    Slide 5 原文喺 H0/H1 嘅括號入面有劃線修改（decrease / increases 對調過）。正確理解：Y = 縮細量（+ve 好）；H0：μ ≤ 0（冇改善：腫瘤增大或不變）；H1：μ > 0（有改善）。

    4. One-sample t-test：Procedure

    Slide 6：

    $$ T = \frac{\bar y}{s/\sqrt n} \quad(\text{當 } \mu_0 = 0)\qquad\text{一般：}\quad T = \frac{\bar y - \mu_0}{s/\sqrt n} $$
    $$ s^2 = \frac{(X_1-\bar X)^2 + \cdots + (X_n - \bar X)^2}{n-1} $$
    • 需要一個 critical value（取決於 significance level α）。如果 T 大過 critical value，就當 T 夠大、改善嘅證據夠強 → reject H0。
    • 傳統上 critical value 喺 t-table 查。

    4.1 查 t-table（slides 7–8）

    Slide 7 嘅 t-table（“Percentage Points \( t_{\alpha,\nu} \) of the t Distribution”）：column = α（significance level，右尾面積），row = ν = n − 1（degree of freedom），格入面 = critical value（x 軸值）。

    ⭐ 查表步驟（slide 8）
    1. Degree of freedom：one-sample 問題 ν = n − 1。
    2. Level of significance α：5%（較低標準 reject H0）或 1%（較高標準）。
    3. 例：n = 10、α = 5% → 行 ν = 9、欄 .05 → critical value = 1.833。
    4. Python：scipy.stats.t.ppf(0.95, 9) = 1.833（t-distribution with ν = 9 嘅 95% quantile）。

    5. Worked example：腫瘤數據（slides 9–12）

    Changes：4.7, −2.4, 2.1, 1.9, −1.4, 5.7, −0.2, 0.3, 3.9, 2.8。Mean = 1.74 > 0。有冇證據顯示改善係正？α = 0.05。

    ⭐ 手計 5 步
    1. Hypotheses：\( H_0:\mu\le 0 \)；\( H_1:\mu>0 \)（right-tailed；H1 係 > → H0 係 ≤）。
    2. α = 0.05。
    3. Test statistic：
      • \( \bar y = 17.4/10 = 1.74 \)
      • \( \sum (y_i-\bar y)^2 = 63.224 \) → \( s^2 = 63.224/9 = 7.025 \) → \( s = 2.6505 \)
      • \( s/\sqrt n = 2.6505/3.1623 = 0.8381 \)
      • \( T = 1.74/0.8381 = \mathbf{2.076} \)
    4. Critical value：ν = 9、α = 0.05 → 1.833。（p-value = 1 − t.cdf(2.076, 9) = 0.0339）
    5. Decision：2.076 > 1.833（p = 0.0339 < 0.05）→ reject H0。結論：有證據顯示治療令腫瘤縮細（「腫瘤增大或不變」被 reject）。
    import numpy as np
from scipy import stats
y = np.array([4.7, -2.4, 2.1, 1.9, -1.4, 5.7, -0.2, 0.3, 3.9, 2.8])
stats.ttest_1samp(y, 0, alternative='greater')     # H1 是 > → H0 是 <=
# TtestResult(statistic=2.0760103699294623, pvalue=0.03385076318199434, df=9)

# 另一種方法得到同一個 probability（slide 12）
T = y.mean() / (np.sqrt(y.var(ddof=1)) / np.sqrt(10))   # 2.0760（ddof=1 → 除 n-1）
p = 1 - stats.t.cdf(T, df=9)                              # 0.0339
crit = stats.t.ppf(0.95, 9)                               # 1.833

    Slide 10 嘅解讀：p-value = 假設 H0 正確下，得到觀察值（或更極端）嘅機會。p-value 細過 α = 0.05 → ‘H0 is rejected’。H0：mean ≤ 0；結論：H0 被 reject，即「腫瘤增大或不變」被 reject。

    5.1 三個等價嘅 decision rule（slide 11）

    ⭐ 以下三句意思一樣 
    T > t.ppf(0.95, 9)        # test statistic 大過 critical value
t.cdf(T, 9) > 0.95        # T 嘅 cumulative probability 大過 95%
1 - t.cdf(T, 9) < 0.05    # p-value 細過 α

    1 - t.cdf(T, 9) 就係 p-value。Decision rule：比較 p-value 同你揀嘅 α。p-value 冇電腦好難計（所以以前用 t-table + critical value）。

    5.2 Assumptions（slide 13）

    • n 個 unrelated 病人；佢哋嘅嚴重程度、性別、年齡等相近。
    • 需要假設：\( y_1, \dots, y_n \) 係 independent and identically-distributed (i.i.d.) normal random numbers。
    🔗 跨科連繫

    Normal assumption 可以用 Module 2c 嘅 QQ-plot 或 stats.normaltest 檢查。

    7. Worked example：牛油有冇呃秤？（slides 16–18）

    牛油廠聲稱每包 50 g。抽 10 包：45.3, 52.4, 47.9, 48.1, 51.4, 44.3, 50.2, 49.7, 46.1, 47.2。Mean = 48.26 < 50。有冇證據顯示牛油一般輕過聲稱？Y i.i.d. normal，α = 0.05。

    ⭐ 手計 5 步
    1. H0：μ ≥ 50；H1：μ < 50（left-tailed）。
    2. α = 0.05。
    3. \( \bar y = 48.26 \)，s = 2.6505，SE = 0.8381；\( T = (48.26-50)/0.8381 = \mathbf{-2.076} \)。
    4. Critical value：−\( t_{0.05,9} \) = −1.833；p-value = t.cdf(−2.076, 9) = 0.0339。
    5. −2.076 < −1.833（p = 0.0339 < 0.05）→ reject H0：有證據顯示牛油平均輕過 50 g。
    y = np.array([45.3, 52.4, 47.9, 48.1, 51.4, 44.3, 50.2, 49.7, 46.1, 47.2])
stats.ttest_1samp(y, 50, alternative='less')
# TtestResult(statistic=-2.0760103699294645, pvalue=0.03385076318199426, df=9)
    💡 有趣觀察

    牛油數據其實 = 50 − 腫瘤數據（50 − 4.7 = 45.3、50 + 2.4 = 52.4 …），所以 s 一樣、|T| 一樣、p-value 一樣（slide 18 output 同 slide 10 一樣係 0.03385）——只係方向相反。

    8. Confidence interval（slides 19–20）

    CI 通常由 two-sided problem 嘅 decision rule 定義。Two-sided 唔 reject 嘅條件係 \( |T| < t_{\alpha/2,n-1} \)，代入 \( T = (\bar y-\mu_0)/(s/\sqrt n) \) 整理：

    $$ \bar y - t_{\alpha/2,\,n-1}\frac{s}{\sqrt n} \;<\; \mu_0 \;<\; \bar y + t_{\alpha/2,\,n-1}\frac{s}{\sqrt n} $$

    呢個就係 \( \mu_0 \) 嘅 confidence interval——即係「所有唔會被 two-sided test reject 嘅 μ0」嘅集合。

    Meaning of 95% CI（slide 20）：95% chance that the random confidence interval covers the true value（統計學家用 simulation 驗證 95%，初學者可略）。

    ⭐ Worked example：牛油 95% CI
    1. \( t_{0.025,9} = 2.262 \)；SE = 0.8381
    2. Margin = 2.262 × 0.8381 = 1.896
    3. 95% CI = 48.26 ± 1.896 = (46.36, 50.16)

    注意：CI 包含 50！所以 two-sided test（H1：μ ≠ 50）喺 α = 0.05 唔會 reject（two-sided p = 2 × 0.0339 = 0.0677 > 0.05）；但 one-sided（H1：μ < 50）就 reject。one-sided test 將 α 全放喺一邊，所以較易 reject——H1 嘅方向要喺睇數據之前定好。

    Slide 26：

    • Model assumptions：\( W_1,\dots,W_n \sim N(\mu,\sigma^2) \) i.i.d.
    • Test：\( H_0:\mu\le 0 \) against \( H_1:\mu>0 \)
    • Decision rule：reject H0 if \( t > t_{\alpha,n-1} \)，n = number of pairs。
    • p-value：reject H0 if p-value < α。
    $$ t = \frac{\bar W}{S/\sqrt n}, \qquad S = \text{sample s.d. of } W $$
    💡 直覺理解

    Paired t-test 其實就係對差值 W 做 one-sample t-test（μ0 = 0）。配對抵消咗「人與人之間」嘅差異（例如孿生子天資相近），所以比 independent design 更準。

    ⭐ Worked example：Drug vs Placebo（slides 27–28，數值由本頁按公式計算）

    x (Drug) = 120, 132, 100, 115, 143；y (Placebo) = 115, 95, 106, 108, 97。同一病人 → paired。α = 0.05。

    1. H0：\( \mu_W \le 0 \)；H1：\( \mu_W > 0 \)（藥物較好）。
    2. W = x − y = 5, 37, −6, 7, 46 → \( \bar W = 89/5 = 17.8 \)
    3. \( \sum (W-\bar W)^2 = 2010.8 \) → \( S^2 = 2010.8/4 = 502.7 \) → S = 22.421
    4. \( t = 17.8/(22.421/\sqrt5) = 17.8/10.027 = \mathbf{1.775} \)
    5. Critical value：df = 5 − 1 = 4，α = 0.05 → 2.132（slide 28 t-table 圈住嘅值）
    6. 1.775 < 2.132 → do not reject H0（p ≈ 0.075）。冇足夠證據顯示藥物比 placebo 好。
    x = np.array([120, 132, 100, 115, 143])   # Drug
y = np.array([115, 95, 106, 108, 97])     # Placebo
stats.ttest_rel(x, y, alternative='greater')        # paired t-test：t ≈ 1.775, p ≈ 0.075
stats.ttest_1samp(x - y, 0, alternative='greater')  # 完全一樣嘅結果
stats.t.ppf(0.95, 4)                                 # critical value 2.132
    🖼️ 圖片內容

    Slide 27–28 只顯示數據同 t-table（圈住 ν = 4、α = .05 嘅 2.132），冇顯示 Python output；上面嘅 t = 1.775、p ≈ 0.075 係按 slide 26 公式自行計算。Slide 22 係教學法比較嘅示意圖，冇額外文字。

    孿生子數據（slide 25）同樣做法：\( \bar W = 16.8 \)，S = 22.05，t = 16.8/(22.05/√5) = 1.704 < 2.132 → do not reject。

    11. Independent two-sample t-test（pooled variance）

    Slides 29–30：10 個唔相關學生／病人，5 個用 A、5 個用 B（X1–X5 = 120, 132, 100, 115, 143；Y1–Y5 = 115, 95, 106, 108, 97）。

    Slide 31 model assumptions：\( X_1,\dots,X_n \sim N(\mu_X,\sigma^2) \) 同 \( Y_1,\dots,Y_m \sim N(\mu_Y,\sigma^2) \)，兩個 independent i.i.d. samples，same population variance \( \sigma^2 \)。

    $$ S_p^2 = \frac{\sum_{i=1}^{n}(X_i-\bar X)^2 + \sum_{j=1}^{m}(Y_j-\bar Y)^2}{n+m-2} = \frac{(n-1)S_X^2 + (m-1)S_Y^2}{n+m-2} $$

    Pooled variance 唔同於將 X、Y 合埋一齊計嘅 variance。

    💡 Slide 32：Between-group vs Within-group variation

    一個只有 8 個員工嘅虛構城市：Sector A (Education) 薪金 12534, 13290, 10326, 11973；Sector B (Medical) 76245, 79034, 73453, 77024。Overall variance 好大，但每組內部 variance 好細。合併計 variance ≈ 1.19 × 10⁹，但 pooled variance 只係 ≈ 3.46 × 10⁶。Pooled variance 只量度組內差異，兩組之間嘅差異留俾分子 \( \bar X - \bar Y \)。同樣嘅 between-group / within-group 概念亦用喺 classification / clustering。

    $$ T = \frac{\bar X - \bar Y}{s_p\sqrt{\dfrac1n + \dfrac1m}}, \qquad s_p = \sqrt{\frac{(n-1)S_X^2 + (m-1)S_Y^2}{n+m-2}}, \qquad df = n+m-2 $$

    Slide 33：Test \( H_0:\mu_X=\mu_Y \) against \( H_1:\mu_X\ne\mu_Y \)；reject H0 if \( |T| > t_{\alpha/2,\,n+m-2} \)。

    ⭐ Worked example：薪金數據（slides 32–35，數值由本頁按公式計算）
    1. H0：\( \mu_X = \mu_Y \)；H1：\( \mu_X \ne \mu_Y \)（two-sided），α = 0.05。
    2. \( \bar X = 12030.75,\ \bar Y = 76439 \)
    3. \( S_X^2 = 1{,}582{,}826.25,\ S_Y^2 = 5{,}343{,}360.67 \)
    4. \( S_p^2 = \dfrac{3(1582826.25) + 3(5343360.67)}{4+4-2} = 3{,}463{,}093.5 \) → \( s_p = 1860.94 \)
    5. SE = \( 1860.94\sqrt{1/4+1/4} = 1860.94 \times 0.7071 = 1315.88 \)
    6. \( T = (12030.75 - 76439)/1315.88 = \mathbf{-48.95} \)
    7. df = 4 + 4 − 2 = 6；two-sided α = 0.05 → 查 .025 欄 → 2.447（slide 35 圈住嘅值）
    8. |−48.95| > 2.447 → reject H0：兩個 sector 平均薪金有顯著分別。
    x = np.array([12534, 13290, 10326, 11973])
y = np.array([76245, 79034, 73453, 77024])
stats.ttest_ind(x, y, equal_var=True)      # pooled-variance t-test：T ≈ -48.95, df = 6
stats.t.ppf(0.975, 6)                      # two-sided critical value 2.447
# 如果兩組 variance 唔相等 → Welch's t-test（flowchart 嘅 unpooled）：
stats.ttest_ind(x, y, equal_var=False)
    ⚠️ 常見錯誤
    • Slide 33 寫 “Reject H0 if T > \( t_{\alpha/2} \)”，two-sided 應理解為 |T| > \( t_{\alpha/2,n+m-2} \)（呢個例子 T 係負數）。
    • Paired df = 對數 − 1；Independent df = n + m − 2。用錯 df 就查錯表。
    • 同一組數據（drug vs placebo）如果錯當 independent：T = 2.168，df = 8，two-sided critical 2.306 → 結論亦唔同。Design 決定 test，唔係數據樣子。
    🔗 跨科連繫

    Between-group / within-group variation 嘅比較係 1-way ANOVA（> 2 groups）同 Module 4 regression ANOVA F-test 嘅核心；亦同 COM6004 Cluster Analysis 嘅 SSE（within-cluster）vs between-cluster separation 同一個 idea。

    自我測驗 Self-test

    Q1. n = 16，\( \bar y = 103 \)，s = 8。Test H0：μ ≤ 100 vs H1：μ > 100，α = 0.05。

    T = (103 − 100)/(8/4) = 1.5；df = 15，\( t_{0.05,15} \) = 1.753。1.5 < 1.753 → do not reject H0。冇足夠證據顯示 μ > 100。

    Q2. 同上數據，求 μ 嘅 95% CI。

    \( t_{0.025,15} \) = 2.131；margin = 2.131 × 2 = 4.262；CI = (98.74, 107.26)。

    Q3. stats.t.ppf(0.95, 9)、stats.t.ppf(0.975, 9)、stats.t.ppf(0.05, 9) 分別係幾多？各用喺咩 test？

    1.833（right-tailed α = 0.05）；2.262（two-sided α = 0.05）；−1.833（left-tailed α = 0.05）。

    Q4. T = 2.5，df = 9，one-sided right。寫出三個等價嘅 decision rule 並判斷。

    T > t.ppf(0.95, 9) ⇔ t.cdf(T, 9) > 0.95 ⇔ 1 − t.cdf(T, 9) < 0.05。2.5 > 1.833 → reject H0（p ≈ 0.017）。

    Q5. 以下用邊個 test？(a) 同一班學生上堂前後測驗分數 (b) 隨機分 30 人做 A 組、30 人做 B 組比較減肥效果 (c) 比較 4 個品牌電池壽命 (d) 一批 15 個零件同規格 20 mm 比較

    (a) Paired t-test；(b) Independent two-sample t-test；(c) 1-way ANOVA；(d) One-sample t-test（n < 30）。

    Q6. Paired 數據 W = 3, 5, −1, 4, 4。Test H0：μ ≤ 0 vs H1：μ > 0，α = 0.05。

    \( \bar W \) = 15/5 = 3；偏差平方 0 + 4 + 16 + 1 + 1 = 22；S² = 5.5，S = 2.345；t = 3/(2.345/√5) = 3/1.049 = 2.86；df = 4 → 2.132。2.86 > 2.132 → reject H0。

    Q7. 兩組 independent：n = m = 6，\( \bar X = 20,\ \bar Y = 15,\ S_X^2 = 9,\ S_Y^2 = 16 \)。Two-sided α = 0.05。

    \( S_p^2 \) = (5·9 + 5·16)/10 = 12.5 → s_p = 3.536；SE = 3.536 × √(1/6 + 1/6) = 3.536 × 0.5774 = 2.041；T = 5/2.041 = 2.45；df = 10，\( t_{0.025,10} \) = 2.228。2.45 > 2.228 → reject H0。

    Q8. 點解 pooled variance 唔等於將兩組數據合埋計 variance？用 slide 32 解釋。

    合併 variance 包含組與組之間嘅差距（between-group），薪金例子兩組差 6 萬幾，令合併 variance 極大；pooled variance 只計每組圍繞自己 mean 嘅離散（within-group），反映純 noise。t-test 要嘅係 within-group noise 做分母。

    Q9. 牛油例子 one-sided reject 但 95% CI (46.36, 50.16) 包含 50，矛盾嗎？

    唔矛盾。95% CI 對應 two-sided α = 0.05 test（p = 0.0677，不 reject）；one-sided α = 0.05 test 將 5% 全放左尾，p = 0.0339 → reject。對應 one-sided 嘅應該係 90% two-sided CI（或 one-sided upper bound）。

    一頁總結 Cheat sheet

    ⭐ 考前速記
    • Flowchart：1 sample n < 30 → t；n > 30 → Z；2 samples independent → 2-sample t（pooled / unpooled）；paired → paired t；> 2 → ANOVA。
    • t vs Z：σ 未知用 s → t，tails 較厚；df → ∞ 時 t → Z。
    • One-sample：\( T=\frac{\bar y-\mu_0}{s/\sqrt n} \)，df = n − 1，\( s^2=\frac{\sum(y-\bar y)^2}{n-1} \)（ddof=1）。
    • Table：row = df，column = α（右尾）；n = 10、α = .05 → 1.833 = t.ppf(0.95, 9)；two-sided 查 α/2。
    • Right：T > \( t_{\alpha} \)｜Left：T < −\( t_\alpha \)｜Two：|T| > \( t_{\alpha/2} \)。
    • p-value = 1 − t.cdf(T, df)（right-tailed）；p < α → reject。
    • 腫瘤：T = 2.076，p = 0.0339 → reject；牛油：T = −2.076，p = 0.0339 → reject。
    • CI：\( \bar y \pm t_{\alpha/2,n-1}\,s/\sqrt n \)；牛油 95% CI (46.36, 50.16)。
    • Assumption：i.i.d. normal。
    • Paired：W = X − Y，\( t=\bar W/(S/\sqrt n) \)，df = pairs − 1；drug/placebo t = 1.775 < 2.132 → not reject。
    • Independent：\( s_p^2=\frac{(n-1)S_X^2+(m-1)S_Y^2}{n+m-2} \)，\( T=\frac{\bar X-\bar Y}{s_p\sqrt{1/n+1/m}} \)，df = n + m − 2；薪金 T = −48.95，|T| > 2.447 → reject。
    • Python：ttest_1samp、ttest_rel、ttest_ind(equal_var=True)、alternative='greater'/'less'/'two-sided'。
