    Tabular Data & Chi-squared Tests

    🎯 本講重點 (Learning outcomes)

    • 由 categorical data 整 one-way table（value_counts）同 two-way contingency table（pd.crosstab）；用 pd.cut 將 numerical 轉 categorical。
    • 用 stacked / side-by-side bar chart 視覺化 tabular data。
    • Chi-squared test for independence：expected count \( E_{ij} = n_{i\cdot}n_{\cdot j}/n_{\cdot\cdot} \)、χ² statistic、df = (r − 1)(c − 1)、查 chi-square table、stats.chi2_contingency。
    • Chi-squared goodness-of-fit：\( E_i \) 由 H0 嘅 distribution 計、df = K − 1、stats.chisquare。

    ⭐ 考試必溫 Top-5

    1. Expected count：\( E_{ij} = \dfrac{\text{row total}\times\text{column total}}{\text{grand total}} \)；例：Local Math = 300 × 1000/1250 = 240。
    2. \( \chi^2 = \sum\sum \dfrac{(n_{ij}-E_{ij})^2}{E_{ij}} \)；例子 χ² = 55.56 > 5.991 → reject independence。
    3. df：independence = (r − 1)(c − 1)；goodness-of-fit = K − 1。
    4. 查表：df = 2、α = 0.05 → 5.991 = chi2.ppf(0.95, 2)；df = 5 → 11.071。
    5. Goodness-of-fit 朱古力例：E = 100/6 = 16.67，χ² = 8.36 < 11.071，p = 0.1374 → do not reject（uniform）。

    3. Chi-squared test for independence

    Slides 10–11：本地生同外地生揀主修科目嘅偏好有冇分別？

    • Situation：兩欄 categorical data。
    • X = origin（Local / Foreign）；Y = first subject choice（Math / Computer / Literature）。
    • Question：Is it evident that X and Y are related?
    • H0：independent；H1：related / dependent。

    3.1 Observed 同 expected counts（slide 12）

    LocalForeignSubtotals
    Math25050300 = \( n_{Mat\cdot} \)
    Computer40050450 = \( n_{Com\cdot} \)
    Literature350150500 = \( n_{Lit\cdot} \)
    Subtotals1000 = \( n_{\cdot Loc} \)250 = \( n_{\cdot For} \)1250 = \( n_{\cdot\cdot} \)

    Idea：如果冇 dependence，揀 Math 嘅 300 個學生應該按 Local : Foreign = 1000 : 250 嘅比例分配。Local 比例 = 1000/1250，所以 Expected Local Math = 300 × 1000/1250 = 240。

    $$ E_{ij} = \frac{n_{i\cdot}\, n_{\cdot j}}{n_{\cdot\cdot}} = \frac{\text{row total}\times\text{column total}}{\text{grand total}} $$
    $$ \chi^2 = \sum_{i=1}^{r}\sum_{j=1}^{c}\frac{(n_{ij}-E_{ij})^2}{E_{ij}} $$

    （slide 13）如果冇 dependence，\( n_{ij} \) 應該接近 \( E_{ij} \)。χ² 大過 critical value → dependence 證據強。Critical value 喺 chi-square table 查；建議用 p-value：p-value < α → reject “H0：The two columns are independent”。

    ⭐ Worked example：完整手計（5 步）
    1. Hypotheses：H0：origin 同 subject choice independent；H1：dependent。
    2. α = 0.05。
    3. Expected counts：
      ELocalForeign
      Math300×1000/1250 = 240300×250/1250 = 60
      Computer450×1000/1250 = 360450×250/1250 = 90
      Literature500×1000/1250 = 400500×250/1250 = 100
      （檢查：每行、每欄 expected 總和 = observed 總和。）
    4. Test statistic：
      CellOE(O − E)²/E
      Math, Local250240100/240 = 0.417
      Math, Foreign5060100/60 = 1.667
      Computer, Local4003601600/360 = 4.444
      Computer, Foreign50901600/90 = 17.778
      Literature, Local3504002500/400 = 6.25
      Literature, Foreign1501002500/100 = 25
      χ²55.56
    5. Critical value：df = (r − 1)(c − 1) = (3 − 1)(2 − 1) = 2；α = 0.05 → 5.991。
    6. Decision：55.56 > 5.991（p = 8.6 × 10⁻¹³ < 0.05）→ reject H0。結論：學生來源同主修科目選擇有關——外地生較多揀 Literature（150 vs 預期 100）、較少揀 Computer（50 vs 預期 90）。
    💡 直覺理解

    每格 \( (O-E)^2/E \) 係「意外程度」：差距越大、相對 expected 越大，貢獻越多。Foreign × Literature（25）同 Foreign × Computer（17.78）貢獻最大，即係 dependence 主要嚟自外地生嘅選科模式。

    3.2 查 chi-square table（slides 14–15）

    Slide 14 嘅 chi-square table：column = Upper Tail Areas (α)，row = Degrees of Freedom；圖中右尾陰影面積 = α，左邊 1 − α。圈住嘅值：df = 2、α = .05 → 5.991。

    ⭐ 查表要點（slide 15）
    • Degree of freedom ν（independence test）= (r − 1)(c − 1)。
    • α：5%（較低標準 reject H0）或 1%（較高標準）。
    • 例：r = 3、c = 2 → df = 2；α = 5% → critical value = 5.991 = scipy.stats.chi2.ppf(0.95, 2)（chi-square distribution ν = 2 嘅 95% quantile）。

    ⚠️ 常見錯誤
    • Chi-square test 永遠係 right-tailed（χ² ≥ 0，越大越唔似 H0），唔需要 α/2。
    • df 唔係 r × c − 1，係 (r − 1)(c − 1)；r、c 唔計 subtotal 行／欄。
    • 一定要用 counts（次數），唔可以用 percentage 代入公式。
    • （補充）每格 expected count 最好 ≥ 5，否則 chi-square approximation 唔可靠——slide 4 嘅 10 筆 rating 數據 expected 只有 1.2–2.4，只適合示範 code。

    3.3 Python（slides 16–18）

    import numpy as np
from scipy import stats
# 方法 1：直接入兩欄 raw data → 先 crosstab
contingency_table = pd.crosstab(pd.Series(x), pd.Series(y))
chi2, p, dof, expected = stats.chi2_contingency(contingency_table)
# 方法 2：直接入 joint frequency table
Ft = np.array([[250, 50], [400, 50], [350, 150]])
chi2, p, dof, expected = stats.chi2_contingency(Ft)
# Chi2ContingencyResult(statistic=55.5555, pvalue=8.635e-13, dof=2,
#   expected_freq=array([[240., 60.], [360., 90.], [400., 100.]]))
    ⭐ 三個等價 decision rule（slide 18） 
    chi2 > chi2.ppf(0.95, 2)       # statistic 大過 critical value
chi2.cdf(chi2, 2) > 0.95       # cumulative prob 大過 95%
1 - chi2.cdf(chi2, 2) < 0.05   # p-value 細過 α

    1 - chi2.cdf(chi2, 2) 就係 p-value。Python 嘅 scipy.stats.chi2_contingency() 一次過做晒。

    ⚠️ 留意

    Slide 16 寫 “In chisq.test()…”——chisq.test() 係 R 嘅函數名；Python 對應係 stats.chi2_contingency()。另外 2×2 table 時 scipy 預設做 Yates' continuity correction（correction=True），所以結果會同手計少少唔同。

    4. Chi-squared goodness-of-fit

    Slide 20：

    • Situation：一欄 categorical data。
    • Example：雜錦朱古力嘅顏色係咪均勻分佈（evenly distributed）？
    • Question：Is it evident that the distribution of (yellow, red, orange, brown, blue, green) is not even?
    • H0：The distribution is even，即 (1/6, 1/6, 1/6, 1/6, 1/6, 1/6)。H1：The distribution is not even (uniformly distributed)。
    • Experiment：買一包嚟數。
    YellowRedOrangeBrownBlueGreenTotal
    20 (\( n_1 \))13 (\( n_2 \))12 (\( n_3 \))12 (\( n_4 \))18 (\( n_5 \))25 (\( n_6 \))100
    $$ E_i = n \times p_i, \qquad \chi^2 = \sum_{i=1}^{K}\frac{(n_i-E_i)^2}{E_i}, \qquad df = K-1 $$
    ⭐ Worked example：朱古力顏色（slides 21–23）
    1. Hypotheses：H0：6 種顏色各佔 1/6；H1：唔係均勻。
    2. α = 0.05。
    3. Expected：uniform → 每色 \( E_i = 100/6 = 16.67 \)。
    4. Test statistic：
      ColourOE(O − E)²/E
      Yellow2016.670.667
      Red1316.670.807
      Orange1216.671.307
      Brown1216.671.307
      Blue1816.670.107
      Green2516.674.167
      χ²8.36
    5. Critical value：df = K − 1 = 6 − 1 = 5；α = 0.05 → 11.071（slide 22 圈住）。
    6. Decision：8.36 < 11.071（p-value = 0.1374 > 0.05）→ H0 is not rejected。結論（slide 23）：We cannot statistically reject the null hypothesis that the distribution is uniform。
    from scipy import stats
obs = [20, 13, 12, 12, 18, 25]
stats.chisquare(obs)                          # 預設 expected = 平均分配
# Power_divergenceResult(statistic=8.36, pvalue=0.1374)
stats.chisquare(obs, f_exp=[100/6]*6)         # 明確指定 expected
stats.chi2.ppf(0.95, 5)                       # 11.071
1 - stats.chi2.cdf(8.36, 5)                   # p-value 0.1374

    Slide 24：同樣三個等價 rule（df = 5）：chi2 > chi2.ppf(0.95, 5) ⇔ chi2.cdf(chi2, 5) > 0.95 ⇔ 1 - chi2.cdf(chi2, 5) < 0.05；Python 用 stats.chisquare()。

    ⚠️ 常見錯誤
    • Goodness-of-fit df = K − 1（類別數 − 1），唔係 (r − 1)(c − 1)。
    • H0 唔一定係 uniform：例如 H0 可以係 (0.3, 0.2, 0.2, 0.1, 0.1, 0.1)，咁 \( E_i = 100 \times p_i \)，要用 f_exp= 指定。
    • “Not rejected” ≠ 「證明係 uniform」，只係冇足夠證據話唔係。

    自我測驗 Self-test

    Q1. 2×2 table：男 吸煙 30、不吸煙 70；女 吸煙 20、不吸煙 80。求所有 expected counts。

    Row totals：男 100、女 100；column totals：吸煙 50、不吸煙 150；N = 200。E(男, 吸煙) = 100 × 50/200 = 25；E(男, 不吸煙) = 75；E(女, 吸煙) = 25；E(女, 不吸煙) = 75。

    Q2. 繼續 Q1：計 χ²（不用 continuity correction），df = ?，α = 0.05 結論？

    (30−25)²/25 = 1；(70−75)²/75 = 0.333；(20−25)²/25 = 1；(80−75)²/75 = 0.333；χ² = 2.667。df = (2−1)(2−1) = 1，critical 3.841。2.667 < 3.841 → do not reject：冇足夠證據顯示性別同吸煙有關。

    Q3. 一個 4×3 contingency table 嘅 df 係幾多？α = 0.01 critical value？

    df = (4 − 1)(3 − 1) = 6；α = 0.01 → 16.812。

    Q4. 骰子擲 60 次：1–6 點分別出現 8, 9, 12, 11, 6, 14 次。用 α = 0.05 檢驗骰子是否公平。

    E = 10。χ² = (4 + 1 + 4 + 1 + 16 + 16)/10 = 4.2。df = 5，critical 11.071。4.2 < 11.071 → do not reject：冇證據顯示骰子唔公平。

    Q5. 某品牌聲稱顏色比例係 Red 40%、Blue 30%、Green 30%。抽 200 粒：Red 95、Blue 50、Green 55。寫 expected 同 χ²。

    E = 80, 60, 60。χ² = 225/80 + 100/60 + 25/60 = 2.8125 + 1.6667 + 0.4167 = 4.896。df = 2，critical 5.991 → do not reject。Python：stats.chisquare([95,50,55], f_exp=[80,60,60])。

    Q6. 寫出三個等價嘅 decision rule（df = 2，α = 0.05）。

    chi2 > chi2.ppf(0.95, 2)；chi2.cdf(chi2, 2) > 0.95；1 - chi2.cdf(chi2, 2) < 0.05。

    Q7. pd.cut([35, 55, 56], bins=[0, 35, 55, float('inf')], labels=["young","middle","senior"]) 結果係咩？

    young, middle, senior（bins 右閉：35 ∈ (0,35]，55 ∈ (35,55]，56 ∈ (55,∞)）。

    Q8. 點解 chi-square test 唔分 one-tailed / two-tailed？

    χ² 係平方和，永遠 ≥ 0；任何方向嘅偏離（O > E 或 O < E）都會令 χ² 變大，所以 rejection region 只喺右尾。

    一頁總結 Cheat sheet

    ⭐ 考前速記
    • One-way table：pd.Series(x).value_counts()；two-way：pd.crosstab(x, y)；binning：pd.cut(x, bins, labels)（右閉）。
    • Plot：ft.T.plot(kind='bar'/'barh', stacked=True/False)。
    • Independence：H0 independent；\( E_{ij}=\frac{\text{row}\times\text{col}}{N} \)；df = (r − 1)(c − 1)；chi2_contingency。
    • Goodness-of-fit：H0 指定 distribution；\( E_i = np_i \)；df = K − 1；chisquare。
    • \( \chi^2=\sum (O-E)^2/E \)；永遠 right-tailed；用 counts。
    • Critical：df 1 → 3.841｜df 2 → 5.991｜df 5 → 11.071（α = 0.05）；chi2.ppf(0.95, df)。
    • p-value = 1 - chi2.cdf(stat, df)；p < α → reject。
    • 例 1：Local/Foreign × Math/Computer/Lit：E = 240/60, 360/90, 400/100；χ² = 55.56 → reject（dependent）。
    • 例 2：朱古力 6 色：E = 16.67；χ² = 8.36、p = 0.1374 → not reject（uniform）。
