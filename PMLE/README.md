# PMLE source PDFs

The Google Professional Machine Learning Engineer exam-dump PDFs live here locally but are
**not committed** (see the root `.gitignore`). The app doesn't need them: every question is already
in `quiz-app/data/questions.json`.

They are only needed to re-run `npm run extract`, which expects
`Google-Professional-Machine-Learning-Engineer+解密.pdf` in this folder.
